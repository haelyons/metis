## A — Numerical mechanism audit for CPU/GPU agreement

Propose instrumenting voxelization, FFT correlation and score reduction against independent small-grid direct sums; locate first backend divergence before deriving error bounds. MEGADOCK exposes explicit grid-correlation mathematics, making algorithm audit appropriate here (https://www.bi.cs.titech.ac.jp/megadock/perform.html); sampled agreement alone would not certify frozen four-case tolerance (file:///home/hal/dev/interp/metis/experiments/blind-02/20261103-1649-tree/out/work/seed-20261103/R1/framer.md).

Proposed procedure: freeze historical source and settings; instrument receptor/ligand grids, correlation outputs and selected scores. Build independently specified tiny synthetic grids with known shifts, ties and cutoff gaps; evaluate direct correlations in higher precision and compare CPU/GPU intermediates. Published equation equates spatial correlation with Fourier-domain computation ([equations](https://www.bi.cs.titech.ac.jp/megadock/perform.html)); using this identity as diagnostic reference is proposed adaptation, not published MEGADOCK certification.

Require explicit error model for voxelization, FFT arithmetic, score accumulation and pose reconstruction before turning observations into bounds. Proposed sufficient rank-stability test: if each score error is bounded by ε, score gap greater than 2ε preserves pairwise order; this is triangle-inequality deduction, conditional on valid bound, not measured tolerance. Inspect cutoff boundary using diagnostic access beyond retained output if needed; never count extra candidates as scientific predictions. Fixture success alone cannot prove full-input bounds or DockQ agreement; retain UNKNOWN if independent justification fails ([framer](file:///home/hal/dev/interp/metis/experiments/blind-02/20261103-1649-tree/out/work/seed-20261103/R1/framer.md)).

## B — Fixed-pose score attribution for dense-search ranking failures

Propose decomposing scores on fixed retained poses into shape, electrostatic and desolvation contributions, then reporting which terms favor dense rank1 over best50; these ingredients appear in MEGADOCK's published scoring equations (https://www.bi.cs.titech.ac.jp/megadock/perform.html). Diagnostic only: preserve original ranks, 50 retained poses and native-use restrictions (file:///home/hal/dev/interp/metis/experiments/blind-02/20261103-1649-tree/out/work/seed-20261103/R1/framer.md).

Proposed procedure: audit original poses without reranking. Reconstruct score contributions from frozen implementation and verify their sum reproduces original total, respecting MEGADOCK's packed complex-grid formulation rather than assuming arbitrary independent channels ([equations](https://www.bi.cs.titech.ac.jp/megadock/perform.html)). Use paired rank1/best50 term differences and coordinate overlays to ask which score preference displaced better native agreement. Treat DockQ-selected best50 as retrospective diagnostic comparator, never search guidance ([framer](file:///home/hal/dev/interp/metis/experiments/blind-02/20261103-1649-tree/out/work/seed-20261103/R1/framer.md)).

Optional diagnostic interventions: zero selected score terms or block candidate receptor residues on copies, then inspect score changes on identical poses. Command guide exposes scoring switches and receptor blocking; frozen-pose rescoring still requires implementing and validating diagnostic evaluator ([guide](https://raw.githubusercontent.com/akiyamalab/MEGADOCK/master/doc/README.md)). Label any full redocking after intervention separate experiment. Attribution identifies score mechanism; it does not establish that modifying term improves docking.
