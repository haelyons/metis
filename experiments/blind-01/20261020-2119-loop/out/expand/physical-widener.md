# Physical widener — related compute-constrained problems around the capsid–receptor question

Root question (from framer.md): *Can molecular mapping of AAV capsid–receptor interactions on BMECs determine which AAV variants transcytose across the blood–brain barrier versus remain intracellular, and for which capsid–receptor binding signatures?*

A related problem counts as compute constrained either when it is still open whether more parallel compute would change its answer, or when more parallel compute is already known to bind there (marked `settled:` below); problems whose answer arrives late because one step waits on the previous also count, even where hardware changes only the arrival time and not the answer.

## Structural coverage of capsid–receptor–glycan complexes

Exhaustive AlphaFold-Multimer, cryo-ET and MD modelling of capsid–receptor–glycan complexes across many variants, receptors and pH values would turn epitope geometry and pH-resolved kinetics from a per-complex experiment into a computed prior (method precedent: https://pmc.ncbi.nlm.nih.gov/articles/PMC11381518).

- **Root link:** bears on the "for which capsid–receptor binding signatures" half of the question — whether the epitope-geometry and pH-resolved-kinetics components of a signature can be computed instead of measured per complex.
- **compute_open:** Model runs (capsid–receptor–glycan complexes predicted per pH condition): the largest amount a cited source reports is AlphaFold-Multimer runs of 5 structural models per capsid peptide with up to 20 recycles, paired with cryo-ET sub-tomogram averaging of 85,135 symmetry-expanded particles (https://pmc.ncbi.nlm.nih.gov/articles/PMC11381518), and what is still unknown above that amount is whether any scale of computed coverage recovers epitope geometry and pH-resolved off-rates accurately enough to classify transcytosis versus retention, since the only quantitative pH-resolved benchmark in hand is a single measured pair (ALPL–VCAP-102, K_D ≈ 20 nM at pH 7.4 with rapid dissociation at pH 5.5: https://www.cell.com/molecular-therapy/fulltext/S1525-0016(25)00373-9).
- **sequential:** One run is a chain of roughly 10^9–10^12 integration steps at about 2 fs each, every step waiting on the previous coordinates, and a full answer needs several independent replicas per (capsid, receptor, pH) condition, with one replica keeping a GPU-resident MD engine busy for its whole length (https://pmc.ncbi.nlm.nih.gov/articles/PMC9281402/). The steps must run in order inside a single trajectory, but the answer can be assembled instead from many short independent trajectories started at the same time, which pays off when metastable states separate timescales so replicas decorrelate and weak scaling of independent runs beats strong scaling of one run (https://pmc.ncbi.nlm.nih.gov/articles/PMC9476681/); the nearest source that tried it is adaptive-sampling Markov state modelling, where wall-clock efficiency scaled linearly up to 5,000 parallel simulations per iteration (https://pmc.ncbi.nlm.nih.gov/articles/PMC3637129/).
- **Sources:** https://pmc.ncbi.nlm.nih.gov/articles/PMC11381518 ; https://pmc.ncbi.nlm.nih.gov/articles/PMC9281402/ ; https://pmc.ncbi.nlm.nih.gov/articles/PMC3637129/

## Sequence-to-function ML on binding and transcytosis labels

Fit4Function-style sequence-to-function models trained on paired binding and transcytosis labels could compress the 7-mer/12-mer insert space and design multi-trait libraries with lower false-positive rates (https://www.nature.com/articles/s41467-024-50555-y; https://pubmed.ncbi.nlm.nih.gov/40176349).

- **Root link:** bears on the "determine" verb in its practical reading (D-practical) — whether a classifier built on binding-derived features can be made accurate enough to prioritize variants.
- **compute_open:** Training-set size in labelled capsid variants (and model seeds): published measurements stop at 24K training variants per trait model, where dropping the training set to 5K variants only slightly reduced accuracy (r = 0.924 ± 0.001 versus 0.899 ± 0.015) and six combined models then predicted macaque biodistribution (https://www.nature.com/articles/s41467-024-50555-y), and what is unknown above that amount is whether more labels — and specifically transcytosis labels rather than the liver-targeting labels so far used — lower the false-positive rate of a binding-signature classifier, given that binding rank has failed to predict in vivo BBB transport in published screens (https://pmc.ncbi.nlm.nih.gov/articles/PMC7841218).
- **sequential:** none: the work already splits into independent pieces — each trait model, random seed, codon replicate and held-out library fits on its own, and six independently trained models were combined rather than chained (https://www.nature.com/articles/s41467-024-50555-y).
- **Sources:** https://www.nature.com/articles/s41467-024-50555-y ; https://pmc.ncbi.nlm.nih.gov/articles/PMC7841218

## In-silico search of the capsid insert space

Scoring tens of millions of candidate insert variants per campaign with combined models tests whether the domain of trustworthy binding signatures can be enumerated in silico before any capsid is made (https://www.nature.com/articles/s41467-024-50555-y).

- **Root link:** bears on the domain of the signature→fate function — what the set of trustworthy signatures looks like when candidate signatures can be enumerated at scale.
- **compute_open:** settled: more parallel scoring of candidate variants is already known to change design yield — screening 10M random variants through six combined sequence-to-function models produced a 30K-member MultiFunction library in which 88.4% of variants met all six criteria versus 2.6% of uniformly sampled sequences (https://www.nature.com/articles/s41467-024-50555-y).
- **sequential:** none: every candidate variant is scored independently of every other, so search width parallelizes directly with no step waiting on an earlier one (https://www.nature.com/articles/s41467-024-50555-y).
- **Sources:** https://www.nature.com/articles/s41467-024-50555-y

## Stochastic simulation of post-endocytic sorting

Stochastic simulation of receptor–cargo–endosome partitioning (recycling vs. sorting tubule vs. lysosome) parameterized by measured affinities and valences targets the fate decision the binding map omits (https://www.cell.com/cell-reports/fulltext/S2211-1247(17)31707-2; https://arxiv.org/html/1606.08757).

- **Root link:** bears on the "transcytose versus remain intracellular" outcome itself, which the literature places at the post-endocytic sorting step rather than at binding.
- **compute_open:** Ensemble members (independent stochastic sorting realizations per parameter point): the largest amount a cited source reports is first-passage sorting-time estimates with error bars as standard deviations over many independent simulations for compartments of 20 and 100 vesicle units (https://arxiv.org/html/1606.08757), and what is still unknown above that amount is whether simulated recycling-versus-tubule-versus-lysosome partition probabilities, once parameterized by measured affinity and valence regimes, predict the transcytose/retain label of any real capsid–receptor pair, given that overexpressing one Rab can flip a degradative cargo into a transcytosing one (https://www.cell.com/cell-reports/fulltext/S2211-1247(17)31707-2).
- **sequential:** One run is an event chain — each vesicle-budding or fusion event (in the agent-based formulation, each step's loop of actions over all organelle agents) waits on the previous state of the compartment world — of order the compartment size in vesicle units (tens to hundreds of budding events in the fast regime, with back-fusion resetting progress in the slow regime: https://arxiv.org/html/1606.08757), a parameter point needs many independent realizations, and a single realization is a small serial event loop that leaves most of one GPU idle (https://doi.org/10.1186/s13062-018-0227-4). Within one realization the events must run in order, but realizations and parameter points can run at the same time as an ensemble, which pays off when individual trajectories decorrelate so uncorrelated trajectories carry the same statistics as one long one (https://pmc.ncbi.nlm.nih.gov/articles/PMC9476681/); the nearest source that tried it reports means over many independent simulations of the sorting process (https://arxiv.org/html/1606.08757).
- **Sources:** https://arxiv.org/html/1606.08757 ; https://www.cell.com/cell-reports/fulltext/S2211-1247(17)31707-2 ; https://doi.org/10.1186/s13062-018-0227-4
