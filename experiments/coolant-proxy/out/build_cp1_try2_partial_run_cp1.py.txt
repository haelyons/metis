#!/usr/bin/env python3
"""Runner for one pre-registered experiment: does a cheap number from a short
molecular dynamics run put eight liquids in the same order as their viscosity?

WHAT IS MEASURED, IN PLAIN WORDS
  Eight liquid molecules come from a published simulation study. Each liquid is
  simulated as a box of about 15,000 atoms at 40 degrees Celsius (313.15 K) and
  1 atmosphere. The simulation program is LAMMPS. The interaction parameters
  are a published set tuned for long-chain liquids (the LOPLS-AA force field).

  The runner follows the centre of every molecule. The mean-squared
  displacement (MSD) is the average squared distance a centre has moved after a
  given delay, called the lag. For ordinary diffusion it grows in proportion to
  the lag. One sixth of that slope is the self-diffusion coefficient, D.

  The viscosity stand-in (the proxy) is kT/(6*pi*D*R). Here k is Boltzmann's
  constant and T the temperature. R is the radius of a sphere holding the
  volume one molecule fills at the simulated density.

  The main question: does the proxy rank the eight liquids like their reference
  viscosities? Agreement is scored by Spearman's rank correlation, rho. Rho is
  the ordinary correlation of the two rank orders. Success is rho of 0.8 or more.

WHICH TEXTS BIND THIS FILE, IN ORDER
  1. The execution directive: the addendum at the end of GATE_COMMIT.md.
  2. The gate's item answers above that addendum.
  3. The design record, out/design_record_attempt2.json.
  Where they differ, the earlier one wins. Numbers the design marks as guesses
  are binding. Nothing here re-chooses a number those texts already fixed.

WHERE EACH PART RUNS
  On this workstation, before any rented box is launched (no cost):
    python run_cp1.py prelaunch            # every pre-launch step, in order
    python run_cp1.py prelaunch --step S   # one step: precheck, build, charge,
                                           # zerostep, density, planted, manifest
  Run these with the local toolchain's Python (.toolchain/env/bin/python).
  Records go to out/results_cp1/prelaunch/.

  On the rented box, started by onbox_cp1.sh:
    python run_cp1.py engine      # pick GPU or processor path by a short trial
    python run_cp1.py verify      # check every shipped box file's hash
    python run_cp1.py generate    # the simulations, tier by tier, under the clock
    python run_cp1.py extract     # per-run measurements from the raw output
    python run_cp1.py endpoints   # the twelve endpoints and the summary
  Records go to out/results_cp1/. The box never writes into "prelaunch".

  Anywhere, standard library only:
    python run_cp1.py --selftest

THE SIMULATIONS (the "generate" stage)
  A run is one liquid in one packed box. Each run has three stages:
  25 ps of strain relaxation at 0.5 fs steps, 100 ps at constant volume, and
  1.0 ns at constant pressure with 2 fs steps. The committed equilibration deck
  is used with only the design's listed edits. The final density-matching stage
  is removed, and the centre of every molecule is written every 1 ps. Step
  counts and the timestep are set through the deck's own command-line settings.

  Reruns: three per liquid, each with its own packed box and velocity seed.
  These are same-box reruns: one box size and one GPU session.

  Work runs in priority tiers, four runs at a time (a wave):
    tier 1: reruns 1 and 2 of all eight liquids (16 runs, 9.6 million steps)
    tier 2: rerun 1 of each liquid continued for 1 ns more (8 runs, 4.0 million)
    tier 3: rerun 3 of all eight liquids (8 runs, 4.8 million)
    tier 4: one liquid (nonylcyclohexane) rerun 1 at the deck's own 1 fs step
  The time limit T, in hours from box boot, is min(18.0/P, B/P - 0.75). P is
  the hourly price and B the budget left. Before each wave the runner projects
  its end from the mean length of finished waves. A wave starts only if that
  fits within T less 15 minutes, and only after every higher tier is done.
  In the first wave, a throughput probe reads the measured step rate once each
  of the four runs has done 50,000 constant-pressure steps. If the rest of
  tier 1 (9.0 million steps) cannot fit, all runs stop at once.

VALIDITY, AND HOW A VOID SPREADS
  Every record carries a top-level run_valid field. These void the run:
    - any pre-launch check failing (data-only pre-check, planted checks, ...),
    - tier 1 not finishing (probe stop, clock stop, time limit, failed runs),
    - the density gate failing (endpoint 2).
  A void writes run_valid=false into every record already written, marked as
  voided after the fact, and into every record written afterwards. A void is
  never undone. Records then state the rule's outcome but give no verdict.

RUNNER-CHOSEN NUMBERS, DECLARED
  The binding texts name these checks but fix no number. The runner chose:
    - net charge per molecule counts as near zero at 1e-6 elementary charges
      or less (the builder rounds it to 1e-10);
    - processor cores are split evenly over the four concurrent runs, one
      message-passing rank per core share, on both GPU and processor paths;
    - the engine trial uses tiny step counts and a 1800 s cap per attempt;
    - the runner polls running simulations every 15 s.
  Interpretations, declared:
    - the diffusion window 0.2-1.0 ns holds 801 positions (800 steps of 1 ps);
    - D is the least-squares slope (with intercept) of MSD against every
      whole-picosecond lag in the fit window, divided by 6;
    - the planted bias check pools the relative bias D_fit/D_true - 1 over all
      planted ensembles, with standard error = sample deviation / sqrt(n);
    - planted check (a) uses 20 ensembles for each of the eight molecule
      counts, so three planted rerun sets can be drawn per molecule;
    - the rerun margin is the population standard deviation over every pick;
    - the timestep spread is the sample standard deviation over the reruns;
    - the throughput rate is total steps read from the four logs, divided by
      the wall time since the wave started;
    - "time limit" means running simulations are stopped when T is reached.
"""

_PROV = None


def provenance():
    """Load the frozen record writer from frozen/ or from beside this file."""
    global _PROV
    if _PROV is not None:
        return _PROV
    for cand in (HERE / "frozen" / "provenance.py", HERE / "provenance.py"):
        if cand.exists():
            spec = importlib.util.spec_from_file_location("cp1_provenance", cand)
            mod = importlib.util.module_from_spec(spec)
            spec.loader.exec_module(mod)
            _PROV = mod
            return mod
    raise StageFailure(f"the frozen record writer provenance.py is in neither "
                       f"{HERE / 'frozen'} nor {HERE}")


def utc_now() -> str:
    return datetime.now(timezone.utc).isoformat(timespec="seconds")


def sha256_file(path) -> str:
    h = hashlib.sha256()
    with open(path, "rb") as fh:
        for chunk in iter(lambda: fh.read(1 << 20), b""):
            h.update(chunk)
    return h.hexdigest()


def fsync_write(path, text: str) -> None:
    """Write a file and force it to disk, so a later kill cannot lose it."""
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    tmp = path.with_name(path.name + ".tmp")
    with open(tmp, "w") as fh:
        fh.write(text)
        fh.flush()
        os.fsync(fh.fileno())
    os.replace(tmp, path)


def clean_json(obj):
    """Replace non-finite floats by None so every record is strict JSON."""
    if isinstance(obj, float):
        return obj if math.isfinite(obj) else None
    if isinstance(obj, dict):
        return {str(k): clean_json(v) for k, v in obj.items()}
    if isinstance(obj, (list, tuple)):
        return [clean_json(v) for v in obj]
    return obj


# ---------------------------------------------------------------------------
# Run state: validity, and how a void spreads
# ---------------------------------------------------------------------------
def run_valid_path(results) -> Path:
    return Path(results) / "RUN_VALID.json"


def read_run_state(results) -> dict:
    p = run_valid_path(results)
    if not p.exists():
        return {"run_valid": True, "voided_by": [], "voided_at_utc": None}
    st = json.loads(p.read_text())
    return {"run_valid": bool(st.get("run_valid", True)),
            "voided_by": list(st.get("voided_by", [])),
            "voided_at_utc": st.get("voided_at_utc")}


def write_run_state(results, state: dict) -> None:
    fsync_write(run_valid_path(results), json.dumps(state, indent=2, sort_keys=True))


def ensure_run_state(results) -> dict:
    """Create the validity file if absent. Never turn a false back into true."""
    st = read_run_state(results)
    write_run_state(results, st)
    return st


def _record_paths(results):
    """Every record under this results folder. The box's results folder never
    reaches into a local pre-launch folder, and the reverse."""
    results = Path(results)
    own_is_prelaunch = results.name == "prelaunch"
    for p in sorted(results.rglob("*.json")):
        if p.name in STATE_NAMES:
            continue
        rel = p.relative_to(results).parts
        if not own_is_prelaunch and "prelaunch" in rel:
            continue
        yield p


def void_run(results, reason: str) -> dict:
    """Mark the run invalid and stamp that into every record already written."""
    st = read_run_state(results)
    st["run_valid"] = False
    if reason not in st["voided_by"]:
        st["voided_by"].append(reason)
    st["voided_at_utc"] = st.get("voided_at_utc") or utc_now()
    write_run_state(results, st)
    stamped = 0
    for p in _record_paths(results):
        try:
            rec = json.loads(p.read_text())
        except Exception:
            continue
        if not isinstance(rec, dict) or "decision_rule" not in rec:
            continue
        if rec.get("run_valid") is False and reason in rec.get("run_valid_voided_by", []):
            continue
        was_false = rec.get("run_valid") is False
        rec["run_valid"] = False
        rec["run_valid_voided_by"] = list(st["voided_by"])
        if not was_false:
            rec["run_valid_voided_retroactively"] = True
        fsync_write(p, json.dumps(rec, indent=2, sort_keys=True))
        stamped += 1
    print(f"[void] run_valid=false; reason: {reason}; stamped {stamped} record(s)")
    return st


def write_record(results, *, cell: dict, inputs: list, metric: str, values: dict,
                 threshold: dict | None, decision_rule: str, decision: str,
                 notes: str = "", rows=None, labels=None) -> Path:
    """Write one self-describing record, stamped with the run's validity."""
    prov = provenance()
    results = Path(results)
    results.mkdir(parents=True, exist_ok=True)
    path = results / (prov.cell_slug(cell) + ".json")
    prov.write_result(path, cell=cell, inputs=inputs, metric=metric,
                      values=clean_json(values), threshold=clean_json(threshold or {}),
                      decision_rule=decision_rule, decision=decision, notes=notes,
                      rows=clean_json(rows) if rows is not None else None)
    st = read_run_state(results)
    rec = json.loads(path.read_text())
    rec["run_valid"] = bool(st["run_valid"])
    rec["run_valid_voided_by"] = list(st["voided_by"])
    rec["run_valid_voided_retroactively"] = False
    rec["labels"] = list(labels or [])
    rec["binding_texts"] = SPEC
    fsync_write(path, json.dumps(rec, indent=2, sort_keys=True))
    return path


def load_records(results, stage: str) -> list:
    out = []
    for p in sorted(Path(results).glob("*.json")):
        if p.name in STATE_NAMES:
            continue
        try:
            rec = json.loads(p.read_text())
        except Exception:
            continue
        if isinstance(rec, dict) and (rec.get("cell") or {}).get("stage") == stage:
            rec["_path"] = str(p)
            out.append(rec)
    return out

# ---------------------------------------------------------------------------
# Small arithmetic: ranks, rank correlation, spreads, straight-line fits
# ---------------------------------------------------------------------------
def average_ranks(xs):
    order = sorted(range(len(xs)), key=lambda i: xs[i])
    ranks = [0.0] * len(xs)
    i = 0
    while i < len(order):
        j = i
        while j + 1 < len(order) and xs[order[j + 1]] == xs[order[i]]:
            j += 1
        share = (i + j) / 2.0 + 1.0
        for k in range(i, j + 1):
            ranks[order[k]] = share
        i = j + 1
    return ranks


def spearman(xs, ys) -> float:
    """Rank correlation. Ties take average ranks, then ranks are correlated."""
    if len(xs) != len(ys) or len(xs) < 3:
        raise StageFailure("rank correlation needs two equal lists of three or more")
    rx, ry = average_ranks(xs), average_ranks(ys)
    mx, my = sum(rx) / len(rx), sum(ry) / len(ry)
    sxy = sum((a - mx) * (b - my) for a, b in zip(rx, ry))
    sxx = sum((a - mx) ** 2 for a in rx)
    syy = sum((b - my) ** 2 for b in ry)
    if sxx <= 0 or syy <= 0:
        raise WrongVarianceSource(f"{WRONG_VARIANCE}: one side of a rank correlation "
                                  "has zero spread, so its ranks carry no order")
    return sxy / math.sqrt(sxx * syy)


def rank_sumsq(xs, ys) -> float:
    rx, ry = average_ranks(xs), average_ranks(ys)
    return sum((a - b) ** 2 for a, b in zip(rx, ry))


def pstdev(vals) -> float:
    vals = list(vals)
    m = sum(vals) / len(vals)
    return math.sqrt(sum((v - m) ** 2 for v in vals) / len(vals))


def sstdev(vals) -> float:
    vals = list(vals)
    if len(vals) < 2:
        raise StageFailure("a sample spread needs two or more values")
    m = sum(vals) / len(vals)
    return math.sqrt(sum((v - m) ** 2 for v in vals) / (len(vals) - 1))


def mean(vals) -> float:
    vals = list(vals)
    return sum(vals) / len(vals)


def linfit(xs, ys):
    """Least-squares straight line. Returns (slope, intercept)."""
    n = len(xs)
    if n < 2 or n != len(ys):
        raise StageFailure("a straight-line fit needs two or more paired points")
    mx, my = sum(xs) / n, sum(ys) / n
    sxx = sum((x - mx) ** 2 for x in xs)
    if sxx <= 0:
        raise StageFailure("a straight-line fit needs spread in x")
    sxy = sum((x - mx) * (y - my) for x, y in zip(xs, ys))
    slope = sxy / sxx
    return slope, my - slope * mx


def exact_rho_chance(rho_obs: float, n: int = 8):
    """How many of the n! orders reach at least this rho against a fixed order."""
    base = list(range(1, n + 1))
    hits = 0
    total = 0
    denom = n * (n * n - 1)
    for perm in itertools.permutations(base):
        total += 1
        s = sum((a - b) ** 2 for a, b in zip(base, perm))
        if 1.0 - 6.0 * s / denom >= rho_obs - 1e-12:
            hits += 1
    return hits, total


def family_pairs():
    pairs = []
    for fam in (HYDROCARBONS, OXYGENATES):
        for a, b in itertools.combinations(fam, 2):
            pairs.append((a, b))
    return pairs


def family_concordance(proxy: dict, ref: dict):
    """Count within-family pairs whose proxy order equals reference order."""
    conc, disc = 0, []
    for a, b in family_pairs():
        sp = proxy[a] - proxy[b]
        sr = ref[a] - ref[b]
        if sp * sr > 0:
            conc += 1
        else:
            disc.append(f"{a} vs {b}")
    return conc, disc


def family_offset(proxy: dict, ref: dict):
    """Difference of group means of log(proxy/reference), and its factor."""
    h = mean(math.log(proxy[k] / ref[k]) for k in HYDROCARBONS)
    o = mean(math.log(proxy[k] / ref[k]) for k in OXYGENATES)
    return h - o, math.exp(h - o)


def family_chance():
    """Enumerate both families' 24 x 24 orders: counts with 10+ and 9+ right."""
    ten = nine = total = 0
    base = list(range(4))
    pairs4 = list(itertools.combinations(range(4), 2))
    for p1 in itertools.permutations(base):
        c1 = sum(1 for a, b in pairs4 if p1[a] < p1[b])
        for p2 in itertools.permutations(base):
            c2 = sum(1 for a, b in pairs4 if p2[a] < p2[b])
            total += 1
            if c1 + c2 >= 10:
                ten += 1
            if c1 + c2 >= 9:
                nine += 1
    return ten, nine, total

# Chemistry: formula from the molecule's text code, molar mass, radius, proxy
# ---------------------------------------------------------------------------
ATOMIC_MASS = {"C": 12.011, "H": 1.008, "O": 15.999, "N": 14.007}


def smiles_formula(smiles: str) -> dict:
    """Element counts from a SMILES text code (organic subset, no brackets).

    Implicit hydrogens: aliphatic C has 4 bonds, O has 2, N has 3. A bond
    between two aromatic atoms counts 1.5, and an aromatic carbon keeps
    4 minus the whole part of its bond total as hydrogens.
    """
    atoms = []            # (element, aromatic)
    bond_sum = []
    stack = []
    prev = None
    pending = None
    rings = {}
    orders = {"-": 1.0, "=": 2.0, "#": 3.0}

    def add_bond(a, b, order):
        bond_sum[a] += order
        bond_sum[b] += order

    def default_order(a, b):
        return 1.5 if atoms[a][1] and atoms[b][1] else 1.0

    i = 0
    while i < len(smiles):
        ch = smiles[i]
        if ch in "CNOcno":
            atoms.append((ch.upper(), ch.islower()))
            bond_sum.append(0.0)
            idx = len(atoms) - 1
            if prev is not None:
                add_bond(prev, idx, pending if pending is not None else default_order(prev, idx))
            pending = None
            prev = idx
        elif ch == "(":
            stack.append(prev)
        elif ch == ")":
            if not stack:
                raise ParseError(f"unbalanced ')' in {smiles}")
            prev = stack.pop()
        elif ch in orders:
            pending = orders[ch]
        elif ch.isdigit():
            if prev is None:
                raise ParseError(f"ring digit before any atom in {smiles}")
            if ch in rings:
                j, open_order = rings.pop(ch)
                order = pending if pending is not None else open_order
                if order is None:
                    order = default_order(j, prev)
                add_bond(j, prev, order)
            else:
                rings[ch] = (prev, pending)
            pending = None
        else:
            raise ParseError(f"unsupported character {ch!r} in {smiles}")
        i += 1
    if rings or stack:
        raise ParseError(f"unclosed ring or branch in {smiles}")
    counts = {}
    hydrogens = 0
    valence = {"C": 4, "O": 2, "N": 3}
    for (el, arom), s in zip(atoms, bond_sum):
        counts[el] = counts.get(el, 0) + 1
        h = valence[el] - (math.floor(s + 1e-9) if arom else s)
        if h < -1e-9:
            if arom:
                h = 0
            else:
                raise ParseError(f"over-bonded {el} in {smiles}")
        hydrogens += int(round(max(h, 0)))
    counts["H"] = hydrogens
    return counts


def molar_mass(smiles: str) -> float:
    return sum(ATOMIC_MASS[el] * n for el, n in smiles_formula(smiles).items())


def atoms_per_molecule(smiles: str) -> int:
    return sum(smiles_formula(smiles).values())


def radius_m(molar_mass_g: float, density_g_cm3: float) -> float:
    """Radius of a sphere holding one molecule's volume at this density, metres."""
    v_cm3 = molar_mass_g / (density_g_cm3 * AVOGADRO)
    v_m3 = v_cm3 * 1e-6
    return (3.0 * v_m3 / (4.0 * math.pi)) ** (1.0 / 3.0)


def proxy_mpas(d_a2ps: float, density_g_cm3: float, molar_mass_g: float) -> float:
    """kT/(6 pi D R) in mPa s, with D in square angstrom per picosecond."""
    if not (d_a2ps > 0):
        raise StageFailure("the proxy needs a positive D")
    d_si = d_a2ps * 1e-8
    r = radius_m(molar_mass_g, density_g_cm3)
    return BOLTZMANN * T_KELVIN / (6.0 * math.pi * d_si * r) * 1e3


def planted_d_a2ps(eta_mpas: float, density_g_cm3: float, molar_mass_g: float) -> float:
    """The D that the proxy formula maps back to this viscosity."""
    r = radius_m(molar_mass_g, density_g_cm3)
    d_si = BOLTZMANN * T_KELVIN / (6.0 * math.pi * eta_mpas * 1e-3 * r)
    return d_si / 1e-8

def committed_path(root, name) -> Path:
    return Path(root) / COMMITTED[name][0]


def check_committed(root, name) -> Path:
    p = committed_path(root, name)
    if not p.exists():
        raise StageFailure(f"committed file missing: {p}")
    got = sha256_file(p)
    if got != COMMITTED[name][1]:
        raise StageFailure(f"hash mismatch for {p}: expected {COMMITTED[name][1]}, got {got}")
    return p


def parse_reference_csv(dataset_text: str, predictions_text: str) -> dict:
    """The eight rows of both committed tables, keyed by liquid."""
    import csv
    import io
    ds = {r["molecule_id"]: r for r in csv.DictReader(io.StringIO(dataset_text))}
    pr = {}
    for r in csv.DictReader(io.StringIO(predictions_text)):
        if r["molecule_id"] in pr:
            raise ParseError(f"predictions table repeats {r['molecule_id']}")
        pr[r["molecule_id"]] = r
    out = {}
    for m in MOLECULES:
        if m["id"] not in ds or m["id"] not in pr:
            raise ParseError(f"{m['id']} missing from a committed table")
        d, p = ds[m["id"]], pr[m["id"]]
        out[m["key"]] = {
            "eta": float(d["viscosity_40c"]),
            "density": float(d["density_40c"]),
            "smiles": d["canonical_smiles"],
            "eta_predictions_file": float(p["experimental_40C_mPa_s"]),
            "xgboost": float(p["xgboost_descriptors_40C"]),
            "molar_mass": molar_mass(d["canonical_smiles"]),
        }
    return out

_MONEY_RE = re.compile(r"^([0-9]+(\.[0-9]*)?|\.[0-9]+)$")


def parse_money(text, name: str) -> Fraction:
    if text is None or not str(text).strip():
        raise StageFailure(f"{name} is missing")
    s = str(text).strip()
    if not _MONEY_RE.match(s):
        raise StageFailure(f"{name} is not a number: {s!r}")
    val = Fraction(s)
    if val <= 0:
        raise StageFailure(f"{name} is not above zero: {s!r}")
    return val


def time_limit(price_text, budget_text) -> dict:
    """T = min(18.0/P, B/P - 0.75) hours, computed exactly."""
    p = parse_money(price_text, "PRICE_USD_PER_HOUR")
    b = parse_money(budget_text, "BUDGET_LEFT_USD")
    t = min(PRICE_NUMERATOR / p, b / p - OVERHEAD_HOURS)
    remote = math.floor((t + BACKSTOP_HOURS) * 3600)
    worst = p * (t + BACKSTOP_HOURS + Fraction(1, 4))
    return {"price_usd_per_hour": float(p), "budget_left_usd": float(b),
            "time_limit_hours": float(t), "remote_timeout_seconds": remote,
            "worst_case_usd": float(worst),
            "launch_rule_met": bool(t >= LAUNCH_MIN_HOURS),
            "launch_rule_min_hours": float(LAUNCH_MIN_HOURS)}


def parse_uptime(text: str) -> float:
    tok = text.split()
    if not tok:
        raise ParseError("empty uptime text")
    v = float(tok[0])
    if not math.isfinite(v) or v < 0:
        raise ParseError(f"bad uptime {tok[0]!r}")
    return v


def uptime_hours() -> float:
    return parse_uptime(Path("/proc/uptime").read_text()) / 3600.0


def clock_rule(uptime_h: float, finished_wave_seconds: list, limit_h: float) -> dict:
    """The design's rule: a wave starts only if its projected end fits."""
    if not finished_wave_seconds:
        return {"fits": True, "mean_wave_seconds": None, "projected_end_hours": None,
                "note": "no finished wave yet; the first wave is guarded by the probe"}
    m = mean(finished_wave_seconds)
    proj = uptime_h + m / 3600.0
    return {"fits": proj <= limit_h - SPARE_HOURS, "mean_wave_seconds": m,
            "projected_end_hours": proj}


def probe_rule(uptime_h: float, rate_steps_per_s: float, limit_h: float) -> dict:
    """Gate item D5: hours used plus 9.0 million steps at the measured rate."""
    if not (rate_steps_per_s > 0):
        return {"fits": False, "projected_end_hours": None,
                "note": "no positive rate was measured"}
    proj = uptime_h + PROBE_REMAINING_TIER1 / rate_steps_per_s / 3600.0
    return {"fits": proj <= limit_h - SPARE_HOURS, "projected_end_hours": proj}

def parse_lmp_help(text: str) -> dict:
    """The simulation program's help text: release, packages, accelerators."""
    lines = text.splitlines()
    version = None
    for ln in lines:
        m = re.search(r"Large-scale Atomic/Molecular Massively Parallel Simulator - (.+)$", ln)
        if m:
            version = m.group(1).strip()
            break
    packages = []
    accel = []
    mode = None
    for ln in lines:
        s = ln.strip()
        if s == "Installed packages:":
            mode = "pk"
            continue
        if s == "Accelerator configuration:":
            mode = "acc"
            continue
        if mode == "pk":
            if s.startswith("List of individual style options"):
                mode = None
                continue
            if s:
                packages.extend(s.split())
            elif packages:
                mode = None
        elif mode == "acc":
            if not s:
                if accel:
                    mode = None
                continue
            if s.endswith(":") and " " not in s.rstrip(":"):
                mode = None
                continue
            accel.append(s)
    return {"version": version, "packages": packages, "accelerator_lines": accel}


_LOOP_RE = re.compile(r"^Loop time of\s+(\S+)\s+on\s+(\d+)\s+procs\s+for\s+(\d+)\s+steps")


def parse_lammps_log(text: str) -> dict:
    """Thermo blocks, loop times, errors, warnings and accelerator lines."""
    blocks, errors, warnings, accel, done = [], [], [], [], []
    cur = None
    for raw in text.splitlines():
        s = raw.strip()
        if not s:
            continue
        tok = s.split()
        if tok[0] == "Step" and len(tok) >= 2:
            cur = {"columns": tok, "rows": [], "loop_seconds": None,
                   "loop_procs": None, "loop_steps": None}
            blocks.append(cur)
            continue
        m = _LOOP_RE.match(s)
        if m:
            if cur is not None:
                cur["loop_seconds"] = float(m.group(1))
                cur["loop_procs"] = int(m.group(2))
                cur["loop_steps"] = int(m.group(3))
            cur = None
            continue
        if s.startswith("ERROR") or "Lost atoms" in s or "MPI_ABORT" in s \
                or s.startswith("Segmentation fault"):
            errors.append(s)
        elif s.startswith("WARNING"):
            warnings.append(s)
        if ("Using acceleration for" in s or s.startswith("Device ")
                or "KOKKOS mode" in s or "GPU(s) per node" in s):
            accel.append(s)
        if s.startswith("Equilibration done") or s.startswith("Extension done"):
            done.append(s)
        if cur is not None and len(tok) == len(cur["columns"]):
            try:
                vals = [float(t) for t in tok]
            except ValueError:
                continue
            cur["rows"].append(vals)
    return {"blocks": blocks, "errors": errors, "warnings": warnings,
            "accelerator_lines": accel, "done_lines": done}


def log_column(block: dict, name: str) -> int:
    for i, c in enumerate(block["columns"]):

            return i
    raise ParseError(f"thermo column {name} not found in {block['columns']}")


def main_deck_progress(log: dict) -> dict:
    """Steps done in a main run: completed timed blocks after minimisation,
    plus the current step of the constant-pressure block (block four)."""
    blocks = log["blocks"]
    done = 0
    for b in blocks[1:3]:
        if b["loop_steps"] is not None:
            done += b["loop_steps"]
        elif b["rows"]:
            done += int(b["rows"][-1][0] - b["rows"][0][0])
    stage3 = None
    if len(blocks) >= 4 and blocks[3]["rows"]:
        stage3 = int(blocks[3]["rows"][-1][0])
        done += stage3
    return {"stage3_step": stage3, "steps_done": done, "blocks_seen": len(blocks)}


def parse_ave_time_scalar(text: str) -> list:
    """A time-averaged scalar file: (step, [values]) per line."""
    out = []
    for ln in text.splitlines():
        s = ln.strip()
        if not s or s.startswith("#"):
            continue
        tok = s.split()
        try:
            out.append((int(tok[0]), [float(t) for t in tok[1:]]))
        except ValueError as e:
            raise ParseError(f"bad line in averaged file: {s!r}") from e
    return out


def parse_ave_time_vector(text: str, expected_rows: int | None = None):
    """A time-averaged vector file of molecule centres.

    Each frame is a line "step nrows" then nrows lines "row x y z".
    Returns the steps and one flat array of 3*nrows numbers per frame.
    """
    steps, frames = [], []
    lines = text.splitlines()
    i, n = 0, len(lines)
    while i < n:
        s = lines[i].strip()
        i += 1
        if not s or s.startswith("#"):
            continue
        tok = s.split()
        if len(tok) != 2:
            raise ParseError(f"expected 'step rows', got {s!r}")
        step, nrows = int(tok[0]), int(tok[1])
        if expected_rows is not None and nrows != expected_rows:
            raise ParseError(f"frame at step {step} has {nrows} rows, expected {expected_rows}")
        if i + nrows > n:
            raise ParseError(f"frame at step {step} is cut short")
        buf = array("d")
        for k in range(1, nrows + 1):
            row = lines[i].split()
            i += 1
            if len(row) != 4 or int(row[0]) != k:
                raise ParseError(f"frame at step {step}: bad row {k}: {row!r}")
            buf.append(float(row[1]))
            buf.append(float(row[2]))
            buf.append(float(row[3]))
        steps.append(step)
        frames.append(buf)
    return steps, frames


def format_ave_time_vector(steps, frames, fix_id="cp1_com_out") -> str:
    """Write centres in the same layout the simulation program writes."""
    out = [f"# Time-averaged data for fix {fix_id}", "# TimeStep Number-of-rows",
           "# Row c_cp1_com[1] c_cp1_com[2] c_cp1_com[3]"]
    for st, fr in zip(steps, frames):
        n = len(fr) // 3
        out.append(f"{st} {n}")
        for k in range(n):
            out.append(f"{k + 1} {fr[3 * k]:.10g} {fr[3 * k + 1]:.10g} {fr[3 * k + 2]:.10g}")
    return "\n".join(out) + "\n"


def parse_data_file(text: str) -> dict:
    """The packed box file: atom count, box edges, masses, atoms per type."""
    lines = text.splitlines()
    head = {}
    box = {}
    section = None
    masses = {}
    type_counts = {}
    n_atom_rows = 0
    headers = {"Masses", "Atoms", "Velocities", "Bonds", "Angles", "Dihedrals",
               "Impropers", "Pair Coeffs", "Bond Coeffs", "Angle Coeffs",
               "Dihedral Coeffs", "Improper Coeffs"}
    for ln in lines[1:]:
        s = ln.split("#", 1)[0].strip()
        if not s:
            continue
        if s in headers:
            section = s
            continue
        tok = s.split()
        if section is None:
            if len(tok) == 4 and tok[2] in ("xlo", "ylo", "zlo"):
                box[tok[2][0]] = (float(tok[0]), float(tok[1]))
            elif len(tok) == 2 and tok[1] == "atoms":
                head["atoms"] = int(tok[0])
            elif len(tok) == 3 and tok[1:] == ["atom", "types"]:
                head["atom_types"] = int(tok[0])
            continue
        if section == "Masses":
            masses[int(tok[0])] = float(tok[1])
        elif section == "Atoms":
            t = int(tok[2])
            type_counts[t] = type_counts.get(t, 0) + 1
            n_atom_rows += 1
    if set(box) != {"x", "y", "z"} or "atoms" not in head:
        raise ParseError("data file lacks box edges or atom count")
    if n_atom_rows != head["atoms"]:
        raise ParseError(f"data file lists {n_atom_rows} atoms, header says {head['atoms']}")
    missing = set(type_counts) - set(masses)
    if missing:
        raise ParseError(f"data file atom types without mass: {sorted(missing)}")
    return {"atoms": head["atoms"], "box": box, "masses": masses, "type_counts": type_counts}


def hand_density(parsed: dict) -> float:
    """Total atom mass over box volume, in g/cm3."""
    total_g_mol = sum(parsed["masses"][t] * n for t, n in parsed["type_counts"].items())
    vol_a3 = 1.0
    for ax in "xyz":
        lo, hi = parsed["box"][ax]
        vol_a3 *= (hi - lo)
    return total_g_mol / AVOGADRO / (vol_a3 * 1e-24)


def parse_metadata(text: str) -> dict:
    d = json.loads(text)
    for k in ("n_molecules", "atoms_per_molecule", "net_charge_per_molecule", "smiles"):
        if k not in d:
            raise ParseError(f"builder metadata lacks {k}")
    return d

# Deck text: the design's listed edits, the continuation deck, command lines
# ---------------------------------------------------------------------------
ANCHOR_RUN_NPT = "run             ${npt_steps}"
ANCHOR_UNFIX_NPT = "unfix           eq_npt"
DEFORM_FIRST = "variable        rho_now equal density"
DEFORM_LAST = "unfix           eq_nvt"
COM_EDIT = [
    "# cp1 edit listed in the design: write the unwrapped centre of every molecule every 1 ps",
    "compute         cp1_mol all chunk/atom molecule",
    "compute         cp1_com all com/chunk cp1_mol",
    "fix             cp1_com_out all ave/time ${com_every} 1 ${com_every} c_cp1_com[*] "
    "mode vector format %.10g file ${system_dir}/com_npt_T${T}K_run${run_id}.dat",
]
COM_EDIT_CLOSE = "unfix           cp1_com_out"


def edit_main_deck(text: str) -> str:
    """Apply only the design's listed text edits to the committed deck.

    1. Remove the final density-matching stage (rescale variables, the second
       timestep reset, the constant-volume deform run).
    2. Write the unwrapped centre of every molecule every 1 ps during the
       constant-pressure stage.
    Step counts and the timestep are set by the deck's own command-line
    settings, so they need no text edit.
    """
    lines = text.split("\n")
    for anchor in (ANCHOR_RUN_NPT, ANCHOR_UNFIX_NPT, DEFORM_FIRST, DEFORM_LAST):
        if lines.count(anchor) != 1:
            raise StageFailure(f"deck anchor {anchor!r} occurs {lines.count(anchor)} times")
    a = lines.index(DEFORM_FIRST)
    b = lines.index(DEFORM_LAST)
    if not a < b:
        raise StageFailure("deck density-matching block is out of order")
    lines = lines[:a] + lines[b + 1:]
    i = lines.index(ANCHOR_RUN_NPT)
    lines = lines[:i] + COM_EDIT + lines[i:]
    j = lines.index(ANCHOR_UNFIX_NPT)
    lines = lines[:j + 1] + [COM_EDIT_CLOSE] + lines[j + 1:]
    out = "\n".join(lines)
    for bad in ("match_density", "deform_steps}", "rho_now"):
        if bad in out.replace("variable        deform_steps", ""):
            raise StageFailure(f"density-matching text {bad!r} survived the edit")
    return out

def select_window(steps, frames, dt_fs: float, window_ps):
    """Frames whose time (step number x timestep) lies inside the window."""
    lo, hi = window_ps
    sel_s, sel_f = [], []
    for st, fr in zip(steps, frames):
        t = st * dt_fs / 1000.0
        if lo - 1e-6 <= t <= hi + 1e-6:
            sel_s.append(st)
            sel_f.append(fr)
    return sel_s, sel_f


def time_axis_check(steps, dt_fs: float) -> dict:
    """Gate item I12: frame times come from step number times the run's own
    timestep, never from the frame count. Spacing must be exactly 1.000 ps."""
    if len(steps) < 2:
        return {"ok": False, "frame_spacing_ps": None, "note": "fewer than two frames"}
    gaps = {round((b - a) * dt_fs / 1000.0, 9) for a, b in zip(steps, steps[1:])}
    spacing = min(gaps)
    ok = gaps == {FRAME_PS}
    return {"ok": ok, "frame_spacing_ps": spacing, "distinct_spacings_ps": sorted(gaps),
            "source": "step number x timestep"}


def detect_positions(frames, n_mol: int) -> dict:
    """Degenerate-output detectors on molecule centres. Exact conditions only."""
    nonfinite = 0
    stalled = 0
    bad_rows = 0
    for fr in frames:
        if len(fr) != 3 * n_mol:
            bad_rows += 1
        for v in fr:
            if not math.isfinite(v):
                nonfinite += 1
    for a, b in zip(frames, frames[1:]):
        if a == b:
            stalled += 1
    moved = [False] * n_mol
    if frames and not bad_rows:
        f0 = frames[0]
        for fr in frames[1:]:
            for i in range(n_mol):
                if not moved[i]:
                    j = 3 * i
                    if fr[j] != f0[j] or fr[j + 1] != f0[j + 1] or fr[j + 2] != f0[j + 2]:
                        moved[i] = True
    frozen = 0 if bad_rows else sum(1 for m in moved if not m) if len(frames) > 1 else 0
    flags = []
    if bad_rows:
        flags.append("DEGENERATE_ROW_COUNT")
    if nonfinite:
        flags.append("DEGENERATE_NONFINITE")
    if stalled:
        flags.append("DEGENERATE_STALLED_FRAMES")
    if frozen:
        flags.append("DEGENERATE_FROZEN_MOLECULE")
    return {"flags": flags, "nonfinite_values": nonfinite, "stalled_frame_pairs": stalled,
            "frozen_molecules": frozen, "frames_with_wrong_rows": bad_rows}


def detect_grid(steps, dt_fs: float, window_ps) -> list:
    expected = int(round((window_ps[1] - window_ps[0]) / FRAME_PS)) + 1
    ta = time_axis_check(steps, dt_fs)
    flags = []
    if len(steps) != expected or not ta["ok"]:
        flags.append("DEGENERATE_FRAME_GRID")
    return flags


def detect_msd(msd: dict) -> list:
    if any((not math.isfinite(v)) or v <= 0 for v in msd.values()):
        return ["DEGENERATE_MSD_NONPOSITIVE"]
    return []


def detect_fit(d_val) -> list:
    if d_val is None or not math.isfinite(d_val) or d_val <= 0:
        return ["DEGENERATE_D_NONPOSITIVE"]
    return []


def detect_density(rows, final_step: int) -> tuple:
    """The deck's averaged density: the line at the final step, finite, positive."""
    val = None
    for st, vals in rows:
        if st == final_step and vals:
            val = vals[0]
    if val is None or not math.isfinite(val) or val <= 0:
        return None, ["DEGENERATE_DENSITY"]
    return val, []


def detect_log(log: dict, *, n_blocks: int, final_step: int, done: str) -> list:
    flags = []
    if log["errors"]:
        flags.append("DEGENERATE_LOG_ERROR")
    blocks = log["blocks"]
    last = blocks[-1]["rows"][-1][0] if blocks and blocks[-1]["rows"] else None
    if len(blocks) < n_blocks or last is None or int(last) != final_step \
            or not any(d.startswith(done) for d in log["done_lines"]):
        flags.append("DEGENERATE_LOG_INCOMPLETE")
    for b in blocks:
        for row in b["rows"]:
            if any(not math.isfinite(v) for v in row):
                flags.append("DEGENERATE_LOG_NONFINITE")
                return flags
    return flags


def remove_drift_py(frames, n_mol: int):
    out = []
    for fr in frames:
        cx = sum(fr[0::3]) / n_mol
        cy = sum(fr[1::3]) / n_mol
        cz = sum(fr[2::3]) / n_mol
        g = array("d", fr)
        for i in range(n_mol):
            g[3 * i] -= cx
            g[3 * i + 1] -= cy
            g[3 * i + 2] -= cz
        out.append(g)
    return out


def msd_py(frames, n_mol: int, lags) -> dict:
    """Mean-squared displacement over all time origins and molecules."""
    out = {}
    nf = len(frames)
    for m in lags:
        if m <= 0 or m >= nf:
            raise StageFailure(f"lag {m} outside a {nf}-frame window")
        tot = 0.0
        for t in range(nf - m):
            a, b = frames[t + m], frames[t]
            tot += sum((x - y) ** 2 for x, y in zip(a, b))
        out[m] = tot / ((nf - m) * n_mol)
    return out


def frames_to_numpy(frames, n_mol: int):
    import numpy as np
    buf = b"".join(f.tobytes() for f in frames)
    return np.frombuffer(buf, dtype=np.float64).reshape(len(frames), n_mol, 3).copy()


def msd_numpy(arr, lags) -> dict:
    """The same mean-squared displacement, on an array of shape (frames, n, 3)."""
    import numpy as np
    out = {}
    nf, n = arr.shape[0], arr.shape[1]
    for m in lags:
        if m <= 0 or m >= nf:
            raise StageFailure(f"lag {m} outside a {nf}-frame window")
        d = arr[m:] - arr[:-m]
        out[m] = float(np.einsum("ijk,ijk->", d, d) / ((nf - m) * n))
    return out


def fit_d(msd: dict, lo_ps, hi_ps):
    """D in square angstrom per ps: slope of MSD against lag, divided by 6."""
    lags = [m for m in sorted(msd) if lo_ps - 1e-9 <= m * FRAME_PS <= hi_ps + 1e-9]
    xs = [m * FRAME_PS for m in lags]
    ys = [msd[m] for m in lags]
    slope, _ = linfit(xs, ys)
    return slope / 6.0


def fit_loglog(msd: dict, lo_ps, hi_ps):
    lags = [m for m in sorted(msd) if lo_ps - 1e-9 <= m * FRAME_PS <= hi_ps + 1e-9]
    if any(msd[m] <= 0 for m in lags):
        return None
    xs = [math.log(m * FRAME_PS) for m in lags]
    ys = [math.log(msd[m]) for m in lags]
    slope, _ = linfit(xs, ys)
    return slope


def lag_range(lo_ps, hi_ps):
    return list(range(int(round(lo_ps / FRAME_PS)), int(round(hi_ps / FRAME_PS)) + 1))


def analyse_window(frames, n_mol: int, windows: dict, *, use_numpy: bool, positions=None):
    """D and log-log slope for each named lag window. Drift is removed first."""
    lags = sorted({m for lo, hi in windows.values() for m in lag_range(lo, hi)})
    if use_numpy:
        import numpy as np
        arr = positions if positions is not None else frames_to_numpy(frames, n_mol)
        arr = arr - arr.mean(axis=1, keepdims=True)
        msd = msd_numpy(arr, lags)
    else:
        msd = msd_py(remove_drift_py(frames, n_mol), n_mol, lags)
    d_vals, slopes = {}, {}
    flags = detect_msd(msd)
    for name, (lo, hi) in windows.items():
        try:
            d_vals[name] = fit_d(msd, lo, hi)
        except StageFailure:
            d_vals[name] = None
        slopes[name] = fit_loglog(msd, lo, hi) if not flags else None
    return {"msd": msd, "D": d_vals, "slope": slopes, "flags": flags}


def join_extension(main_steps, main_frames, ext_steps, ext_frames, join_step: int):
    """Join the main centres file and the extension file at the join step."""
    m_idx = {s: i for i, s in enumerate(main_steps)}
    if join_step not in m_idx:
        raise ParseError(f"main file has no frame at the join step {join_step}")
    dup_diff = None
    for s, f in zip(ext_steps, ext_frames):
        if s == join_step:
            g = main_frames[m_idx[join_step]]
            dup_diff = max(abs(a - b) for a, b in zip(f, g)) if len(f) == len(g) else math.inf
    steps = [s for s in main_steps if s <= join_step] + [s for s in ext_steps if s > join_step]
    frames = [f for s, f in zip(main_steps, main_frames) if s <= join_step] + \
             [f for s, f in zip(ext_steps, ext_frames) if s > join_step]
    return steps, frames, {"duplicate_frame_max_abs_diff_A": dup_diff}


def _max_jump(a, b, n_mol: int) -> float:
    best = 0.0
    for i in range(n_mol):
        j = 3 * i
        d = math.sqrt((a[j] - b[j]) ** 2 + (a[j + 1] - b[j + 1]) ** 2 + (a[j + 2] - b[j + 2]) ** 2)
        if d > best:
            best = d
    return best


def join_check(main_steps, main_frames, ext_steps, ext_frames, join_step: int,
               window_start_step: int, n_mol: int) -> dict:
    """Gate item I5, real-data part: the largest one-frame jump of any centre
    across the join must not exceed the largest one-frame jump inside either
    part."""
    p1 = [(s, f) for s, f in zip(main_steps, main_frames) if window_start_step <= s <= join_step]
    p2 = [(s, f) for s, f in zip(ext_steps, ext_frames) if s > join_step]
    if len(p1) < 2 or len(p2) < 2:
        return {"passed": False, "note": "a part has fewer than two frames"}
    in1 = max(_max_jump(a[1], b[1], n_mol) for a, b in zip(p1, p1[1:]))
    in2 = max(_max_jump(a[1], b[1], n_mol) for a, b in zip(p2, p2[1:]))
    across = _max_jump(p1[-1][1], p2[0][1], n_mol)
    return {"passed": across <= max(in1, in2), "jump_across_join_A": across,
            "max_jump_inside_main_A": in1, "max_jump_inside_extension_A": in2}

def gen_brownian(rng, n_mol: int, n_frames: int, d_a2ps: float):
    import numpy as np
    sd = math.sqrt(2.0 * d_a2ps * FRAME_PS)
    steps = rng.normal(0.0, sd, size=(n_frames - 1, n_mol, 3))
    start = rng.uniform(0.0, 50.0, size=(1, n_mol, 3))
    return np.concatenate([start, start + np.cumsum(steps, axis=0)], axis=0)


def gen_power_law(rng, n_mol: int, n_frames: int, d_a2ps: float, exponent: float):
    """Fractional Brownian centres whose MSD grows as lag**exponent.

    Exact circulant-embedding generator (Davies and Harte). Hurst index is
    exponent/2. The per-axis variance at a 1 ps lag is 2*D.
    """
    import numpy as np
    h = exponent / 2.0
    n = n_frames - 1
    k = np.arange(0, n + 1, dtype=float)
    gam = 0.5 * (np.abs(k + 1) ** (2 * h) - 2 * np.abs(k) ** (2 * h) + np.abs(k - 1) ** (2 * h))
    row = np.concatenate([gam, gam[-2:0:-1]])
    lam = np.fft.fft(row).real
    if lam.min() < -1e-9:
        raise StageFailure("power-law generator: negative circulant eigenvalue")
    lam = np.clip(lam, 0.0, None)
    m = row.size
    width = n_mol * 3
    xi = rng.normal(size=(m, width)) + 1j * rng.normal(size=(m, width))
    y = np.fft.fft(np.sqrt(lam / m)[:, None] * xi, axis=0)
    fgn = y.real[:n]
    scale = math.sqrt(2.0 * d_a2ps * FRAME_PS)
    path = np.concatenate([np.zeros((1, width)), np.cumsum(fgn, axis=0)], axis=0) * scale
    start = rng.uniform(0.0, 50.0, size=(1, width))
    return (path + start).reshape(n_frames, n_mol, 3)

    return [array("d", arr[i].reshape(-1).tolist()) for i in range(arr.shape[0])]

def density_gate(dens: dict) -> dict:
    """Endpoint 2: every liquid's mean density inside its band."""
    per = {}
    for k in KEYS:
        lo, hi = MOL[k]["band"]
        v = dens.get(k)
        dev_ref = None if v is None else v / MOL[k]["ref_rho"] - 1.0
        per[k] = {"density": v, "band": [lo, hi],
                  "inside": v is not None and lo <= v <= hi,
                  "deviation_from_reference": dev_ref}
    glycol = per[GLYCOL_KEY]["deviation_from_reference"]
    others = [per[k]["deviation_from_reference"] for k in KEYS if k != GLYCOL_KEY]
    implications = {
        "glycol_ether_8_to_12_percent_below_reference":
            glycol is not None and GLYCOL_DEVIATION[0] <= glycol <= GLYCOL_DEVIATION[1],
        "others_within_5_percent_of_reference":
            all(o is not None and abs(o) <= OTHER_DEVIATION_MAX for o in others),
    }
    return {"per_molecule": per, "passed": all(p["inside"] for p in per.values()),
            "implications_report_only": implications}


def main_decision(rho: float) -> tuple:
    """Endpoint 3 on a valid run: the decision and its labels."""
    if rho >= RHO_BAR - 1e-12:
        return "PASS", [LABEL_PASS_FORM]
    if rho < ABANDON_RHO:
        return "REFUTED_BELOW_ABANDON_LINE", [LABEL_FORM_ONLY, LABEL_ABANDON]
    return "REFUTED", [LABEL_FORM_ONLY]


def stability_decision(pair_rhos: dict) -> str:
    """Endpoint 4: every rerun pair at 0.8 or more."""
    if not pair_rhos:
        return "NOT_JUDGED"
    return "PASS" if all(v >= RHO_BAR - 1e-12 for v in pair_rhos.values()) else "REFUTED"


def added_value_margin(rerun_d: dict, density: dict, ref: dict) -> dict:
    """Endpoint 8's margin: spread of rho over every pick of one rerun's D per
    liquid. Variance source: reruns of the same cell."""
    lists = [rerun_d[k] for k in KEYS]
    mm = {k: ref[k]["molar_mass"] for k in KEYS}
    eta = [ref[k]["eta"] for k in KEYS]
    rhos = []
    for pick in itertools.product(*lists):
        prox = [proxy_mpas(d, density[k], mm[k]) for d, k in zip(pick, KEYS)]
        rhos.append(spearman(prox, eta))
    margin = pstdev(rhos)
    if margin == 0.0:
        raise WrongVarianceSource(f"{WRONG_VARIANCE}: rho is identical over all "
                                  f"{len(rhos)} rerun picks, so the margin is zero")
    return {"margin": margin, "n_picks": len(rhos), "rho_min": min(rhos), "rho_max": max(rhos)}


def added_value_decision(main_rho: float, free: dict, margin: float, ablations: dict) -> dict:
    """Gate item D3(d): claim 5 against the three orderings that need no
    simulation. One over D and simulated density only add labels."""
    best_name = max(free, key=lambda k: free[k])
    best = free[best_name]
    if main_rho <= best + 1e-12:
        decision, labels = "REFUTED", []
    elif main_rho - best <= margin:
        decision, labels = "WITHIN_RERUN_NOISE", [LABEL_NOISE]
    else:
        decision, labels = "PASS", []
    if ablations.get("inverse_D") is not None and ablations["inverse_D"] >= main_rho - 1e-12:
        labels.append(LABEL_SIZE)
    if ablations.get("simulated_density") is not None and \
            ablations["simulated_density"] >= main_rho - 1e-12:
        labels.append(LABEL_DIFFUSION)
    return {"decision": decision, "labels": labels, "best_free": best_name,
            "best_free_rho": best, "difference": main_rho - best, "margin": margin}


def slope_band(slopes: list) -> float:
    """Narrowest symmetric band around 1 holding at least 95% of the slopes."""
    dev = sorted(abs(s - 1.0) for s in slopes)
    need = math.ceil(BAND_FRACTION * len(dev) - 1e-9)
    return dev[need - 1]


def outside_band(slope, half_width: float) -> bool:
    return slope is None or abs(slope - 1.0) > half_width


def nondiffusive_label(count: int) -> list:
    return [LABEL_NONDIFF.format(n=count)] if count >= NONDIFF_LABEL_MIN else []


def window_label(main_rho: float, other_rhos: list) -> list:
    if main_rho >= RHO_BAR - 1e-12 and any(r < RHO_BAR - 1e-12 for r in other_rhos):
        return [LABEL_WINDOW]
    return []


def timestep_decision(d_1fs, d_2fs: list, ran: bool, time_axis_ok: bool) -> dict:
    """Endpoint 12: 1 fs D within 2 standard deviations of the 2 fs reruns."""
    if not ran or d_1fs is None:
        return {"decision": "NOT_JUDGED", "note": "the timestep control did not run"}
    if not time_axis_ok:
        return {"decision": "NOT_JUDGED", "note": "the time-axis check failed"}
    if len(d_2fs) < 2:
        return {"decision": "NOT_JUDGED", "note": "fewer than two 2 fs reruns finished"}
    m = mean(d_2fs)
    sd = sstdev(d_2fs)
    if sd == 0.0:
        raise WrongVarianceSource(f"{WRONG_VARIANCE}: D is identical over the 2 fs reruns")
    diff = abs(d_1fs - m)
    ok = diff <= TIMESTEP_SD_MULT * sd
    return {"decision": "PASS" if ok else "CONDITIONAL_ON_TIMESTEP",
            "difference": diff, "mean_2fs": m, "sd_2fs": sd,
            "labels": [] if ok else [LABEL_TIMESTEP]}


def bias_test(estimates: list, truths: list) -> dict:
    """Recovered-D bias, pooled as relative bias, within 2 standard errors."""
    rel = [e / t - 1.0 for e, t in zip(estimates, truths)]
    mb = mean(rel)
    se = sstdev(rel) / math.sqrt(len(rel))
    if se == 0.0:
        raise WrongVarianceSource(f"{WRONG_VARIANCE}: planted estimates have no spread")
    return {"n": len(rel), "mean_relative_bias": mb, "standard_error": se,
            "passed": abs(mb) <= BIAS_SE_MULT * se}


def planted_proxy_check() -> dict:
    """Gate item I3: made-up viscosities 1..8 mPa s, shuffled with seed 7."""
    etas = list(range(1, 9))
    random.Random(PLANTED_SEED).shuffle(etas)
    planted = dict(zip(KEYS, [float(e) for e in etas]))
    back, worst = {}, 0.0
    for k in KEYS:
        mm = molar_mass(MOL[k]["smiles"])
        d = planted_d_a2ps(planted[k], MOL[k]["paper_rho"], mm)
        back[k] = proxy_mpas(d, MOL[k]["paper_rho"], mm)
        worst = max(worst, abs(back[k] / planted[k] - 1.0))
    rho = spearman([back[k] for k in KEYS], [planted[k] for k in KEYS])
    rev = spearman([back[k] for k in KEYS], [9.0 - planted[k] for k in KEYS])
    ok = worst <= I3_TOLERANCE and abs(rho - 1.0) < 1e-12 and abs(rev + 1.0) < 1e-12
    return {"planted_eta": planted, "recovered_eta": back, "worst_relative_error": worst,
            "rho": rho, "rho_reversed": rev, "passed": ok}


def planted_family_check() -> dict:
    """Gate item I7: planted family orderings and the 576-order enumeration."""
    ref = {m["key"]: m["ref_eta"] for m in MOLECULES}
    known, _ = family_concordance(ref, ref)
    rev, _ = family_concordance({k: 1.0 / v for k, v in ref.items()}, ref)
    scaled = {k: ref[k] * (2.0 if k in HYDROCARBONS else 0.5) for k in KEYS}
    sc, _ = family_concordance(scaled, ref)
    off, factor = family_offset(scaled, ref)
    ten, nine, total = family_chance()
    ok = (known == 12 and rev == 0 and sc == 12 and abs(off - math.log(4.0)) < 1e-12
          and (ten, nine, total) == (26, 68, 576))
    return {"known_order": known, "reversed": rev, "offset_planted": sc,
            "log_offset": off, "offset_factor": factor, "ten_or_more": ten,
            "nine_or_more": nine, "orders": total, "passed": ok}

class RunSpec:
    def __init__(self, molecule: str, rerun: int, kind: str, tier: int, attempt: int = 1):
        self.molecule, self.rerun, self.kind, self.tier, self.attempt = \
            molecule, rerun, kind, tier, attempt

    @property
    def cell(self) -> dict:
        return {"stage": "cell", "molecule": self.molecule, "rerun": self.rerun,
                "kind": self.kind, "attempt": self.attempt}

    @property
    def slug(self) -> str:
        return provenance().cell_slug(self.cell)

    @property
    def steps(self) -> int:
        return {"main": STEPS_MAIN_RUN, "extension": EXT_STEPS,
                "timestep1fs": STEPS_CONTROL_RUN}[self.kind]

    @property
    def timestep_fs(self) -> float:
        return CONTROL_DT_FS if self.kind == "timestep1fs" else MAIN_DT_FS

    @property
    def pack_seed(self) -> int:
        return PACK_SEED_BASE + self.rerun - 1

    def retry(self):
        return RunSpec(self.molecule, self.rerun, self.kind, self.tier, self.attempt + 1)


def plan_tiers() -> dict:
    return {
        1: [RunSpec(k, r, "main", 1) for r in (1, 2) for k in KEYS],
        2: [RunSpec(k, 1, "extension", 2) for k in KEYS],
        3: [RunSpec(k, 3, "main", 3) for k in KEYS],
        4: [RunSpec(CONTROL_KEY, 1, "timestep1fs", 4)],
    }


def system_dirname(molecule: str, pack_seed: int) -> str:
    return f"{molecule}_pack{pack_seed}"

def extract_cell(raw: Path, meta: dict, results: Path, *, use_numpy: bool = True) -> dict:
    """Measurements from one run's verbatim output. Returns record parts."""
    kind = meta["kind"]
    run_id = meta["rerun"]
    n_mol = meta["n_molecules"]
    dt = meta["timestep_fs"]
    flags = []
    values = {k: meta.get(k) for k in ("molecule", "rerun", "kind", "attempt", "tier",
                                        "n_molecules", "timestep_fs", "pack_seed")}
    values["run"] = {k: meta.get(k) for k in ("exit_code", "wall_seconds", "runs_in_wave",
                                               "gpu_hours_share", "accel_path", "steps",
                                               "stopped_reason", "wave")}
    rows = []
    inputs = []
    if meta.get("stopped_reason"):
        flags.append("RUN_STOPPED")
    if meta.get("exit_code") not in (0, None) and not meta.get("stopped_reason"):
        flags.append("RUN_FAILED")
    if kind in ("main", "timestep1fs"):
        npt = MAIN_NPT if dt == MAIN_DT_FS else CONTROL_NPT
        logp = raw / main_log_name(run_id)
        log = parse_lammps_log(logp.read_text()) if logp.exists() else None
        if log is None:
            flags.append("DEGENERATE_LOG_INCOMPLETE")
        else:
            inputs.append(describe(logp))
            flags += detect_log(log, n_blocks=4, final_step=npt, done="Equilibration done")
            values["log_errors"] = log["errors"][:20]
            values["accelerator_lines"] = log["accelerator_lines"][:20]
            if len(log["blocks"]) >= 4 and log["blocks"][3]["rows"]:
                b = log["blocks"][3]
                ci = log_column(b, "Density")
                sel = [r[ci] for r in b["rows"]
                       if PLATEAU_READOUT_PS[0] - 1e-6 <= r[0] * dt / 1000.0
                       <= PLATEAU_READOUT_PS[1] + 1e-6]
                values["density_plateau_020_045ns"] = mean(sel) if sel else None
                values["density_plateau_samples"] = len(sel)
        dp = raw / density_name(run_id)
        if dp.exists():
            inputs.append(describe(dp))
            dval, dflags = detect_density(parse_ave_time_scalar(dp.read_text()), npt)
        else:
            dval, dflags = None, ["DEGENERATE_DENSITY"]
        flags += dflags
        values["density_last250ps"] = dval
        cp = raw / (com_name(run_id) + ".gz")
        if not cp.exists():
            flags.append("DEGENERATE_NO_CENTRES")
        else:
            inputs.append(describe(cp))
            try:
                steps, frames = parse_ave_time_vector(read_text_any(cp), n_mol)
            except ParseError as e:
                flags.append("DEGENERATE_ROW_COUNT")
                values["parse_error"] = str(e)
                steps, frames = [], []
            values["time_axis"] = time_axis_check(steps, dt)
            ws, wf = select_window(steps, frames, dt, D_WINDOW_PS)
            values["window_frames"] = len(ws)
            flags += detect_grid(ws, dt, D_WINDOW_PS)
            det = detect_positions(wf, n_mol)
            values["position_checks"] = det
            flags += det["flags"]
            if wf and not set(flags) & {"DEGENERATE_FRAME_GRID", "DEGENERATE_NONFINITE",
                                         "DEGENERATE_ROW_COUNT"}:
                res = analyse_window(wf, n_mol, LAG_WINDOWS_PS, use_numpy=use_numpy)
                flags += res["flags"]
                values["D_A2_per_ps"] = res["D"]
                values["D_m2_per_s"] = {k: (v * 1e-8 if v is not None else None)
                                        for k, v in res["D"].items()}
                values["loglog_slope"] = res["slope"]
                flags += detect_fit(res["D"].get("main"))
                rows = [{"window": "0.2-1.0 ns", "lag_ps": m * FRAME_PS, "msd_A2": v}
                        for m, v in sorted(res["msd"].items())]
    elif kind == "extension":
        parent = results / "cells" / meta["parent_slug"]
        mp = parent / (com_name(run_id) + ".gz")
        ep = raw / (ext_com_name(run_id) + ".gz")
        logp = raw / ext_log_name(run_id)
        log = parse_lammps_log(logp.read_text()) if logp.exists() else None
        final = MAIN_NPT + EXT_STEPS
        if log is None:
            flags.append("DEGENERATE_LOG_INCOMPLETE")
        else:
            inputs.append(describe(logp))
            flags += detect_log(log, n_blocks=1, final_step=final, done="Extension done")
            values["log_errors"] = log["errors"][:20]
        if not mp.exists() or not ep.exists():
            flags.append("DEGENERATE_NO_CENTRES")
        else:
            inputs += [describe(mp), describe(ep)]
            try:
                ms, mf = parse_ave_time_vector(read_text_any(mp), n_mol)
                es, ef = parse_ave_time_vector(read_text_any(ep), n_mol)
            except ParseError as e:
                flags.append("DEGENERATE_ROW_COUNT")
                values["parse_error"] = str(e)
                ms = mf = es = ef = []
            if ms and es:
                join_step = int(round(JOIN_PS * 1000.0 / dt))
                start_step = int(round(LONG_WINDOW_PS[0] * 1000.0 / dt))
                try:
                    js, jf, jinfo = join_extension(ms, mf, es, ef, join_step)
                    values["join"] = dict(jinfo, **join_check(ms, mf, es, ef, join_step,
                                                              start_step, n_mol))
                except ParseError as e:
                    flags.append("DEGENERATE_JOIN")
                    values["join"] = {"passed": False, "note": str(e)}
                    js, jf = [], []
                values["time_axis"] = time_axis_check(js, dt) if js else {"ok": False}
                ws, wf = select_window(js, jf, dt, LONG_WINDOW_PS)
                values["window_frames"] = len(ws)
                flags += detect_grid(ws, dt, LONG_WINDOW_PS)
                det = detect_positions(wf, n_mol)
                values["position_checks"] = det
                flags += det["flags"]
                if wf and not set(flags) & {"DEGENERATE_FRAME_GRID", "DEGENERATE_NONFINITE",
                                             "DEGENERATE_ROW_COUNT", "DEGENERATE_JOIN"}:
                    res = analyse_window(wf, n_mol, {"long": LONG_LAGS_PS}, use_numpy=use_numpy)
                    flags += res["flags"]
                    values["D_A2_per_ps"] = res["D"]
                    values["D_m2_per_s"] = {k: (v * 1e-8 if v is not None else None)
                                            for k, v in res["D"].items()}
                    values["loglog_slope"] = res["slope"]
                    flags += detect_fit(res["D"].get("long"))
                    rows = [{"window": "0.2-2.0 ns", "lag_ps": m * FRAME_PS, "msd_A2": v}
                            for m, v in sorted(res["msd"].items())]
    flags = sorted(set(flags))
    if "RUN_STOPPED" in flags:
        status = "stopped"
    elif "RUN_FAILED" in flags:
        status = "failed"
    elif flags:
        status = "degenerate"
    else:
        status = "ok"
    values["flags"] = flags
    values["status"] = status
    return {"values": values, "rows": rows, "inputs": inputs, "status": status}


CELL_RULE = ("A run counts as finished only when its program exited cleanly, its log "
             "reached the last step with no error line, its averaged density is present, "
             "and its centres pass every degenerate-output check: frame grid of exactly "
             "1.000 ps from step number x timestep, the expected rows per frame, no "
             "non-finite value, no two identical frames, no molecule that never moves, "
             "positive MSD at every fitted lag, and a positive fitted D. Otherwise it is "
             "failed, degenerate or stopped, and it is not used.")


def record_cell(results: Path, raw: Path, meta: dict, *, use_numpy: bool = True) -> dict:
    out = extract_cell(raw, meta, results, use_numpy=use_numpy)
    cell = {"stage": "cell", "molecule": meta["molecule"], "rerun": meta["rerun"],
            "kind": meta["kind"], "attempt": meta["attempt"]}
    write_record(results, cell=cell, inputs=out["inputs"],
                 metric="per-run density, mean-squared displacement and D",
                 values=out["values"], threshold={"frame_spacing_ps": FRAME_PS},
                 decision_rule=CELL_RULE, decision="CELL_" + out["status"].upper(),
                 notes=LABEL_RERUNS, rows=out["rows"])
    return out

PRELAUNCH_STEPS = ["precheck", "build", "charge", "zerostep", "density", "planted", "manifest"]


def prelaunch_dir(results) -> Path:
    return Path(results) / "prelaunch"


def _fail(results, reason: str) -> int:
    void_run(results, reason)
    print(f"[prelaunch] STOP before launch: {reason}")
    return 1


def toolchain_paths(toolchain: Path) -> dict:
    tc = Path(toolchain)
    return {"python": tc / "bin" / "python", "lmp": tc / "bin" / "lmp",
            "packmol": tc / "bin" / "packmol", "bin": tc / "bin", "meta": tc / "conda-meta"}


def conda_versions(meta_dir: Path, names) -> dict:
    out = {}
    if not Path(meta_dir).exists():
        return out
    for p in Path(meta_dir).glob("*.json"):
        try:
            d = json.loads(p.read_text())
        except Exception:
            continue
        if d.get("name") in names:
            out[d["name"]] = f"{d.get('version')} {d.get('build')} {d.get('channel', '')}".strip()
    return out


def step_passed(pre: Path, step: str, expect: int | None = None) -> bool:
    recs = [r for r in load_records(pre, "prelaunch") if r["cell"].get("step") == step]
    if not recs or (expect is not None and len(recs) != expect):
        return False
    return all(r["decision"] == "PASS" and r.get("run_valid") is True for r in recs)


def prelaunch_precheck(root: Path, pre: Path) -> int:

    v = endpoint_precheck(ref)
    write_record(pre, cell={"stage": "prelaunch", "step": "precheck", "endpoint": 1},
                 inputs=inputs, metric="data-only pre-check (endpoint 1)", values=v,
                 threshold={"rho": 1.0, "order": REFERENCE_ORDER},
                 decision_rule="rho between the two committed tables must be 1.0 and the "

                               "the run before any spend",
                 decision="PASS" if v["passed"] else "FAIL",
                 labels=[LABEL_INTEGRITY] if v["passed"] else [])

def prelaunch_build(root: Path, pre: Path, toolchain: Path, systems: Path) -> int:
    builder = check_committed(root, "builder")
    tc = toolchain_paths(toolchain)
    for need in ("python", "packmol"):
        if not tc[need].exists():
            raise StageFailure(f"toolchain {need} missing at {tc[need]}")
    work = pre / "builder"
    work.mkdir(parents=True, exist_ok=True)
    copy = work / "smiles2loplsaa.py"
    shutil.copyfile(builder, copy)
    if sha256_file(copy) != COMMITTED["builder"][1]:
        raise StageFailure("builder copy hash differs from the committed builder")
    systems.mkdir(parents=True, exist_ok=True)
    env = dict(os.environ, PATH=f"{tc['bin']}{os.pathsep}{os.environ.get('PATH', '')}")
    failed = []
    for m in MOLECULES:
        for r in RERUNS:
            seed = PACK_SEED_BASE + r - 1
            out = systems / system_dirname(m["key"], seed)
            if out.exists():
                raise StageFailure(f"{out} already exists; build into a fresh folder")
            cmd = [str(tc["python"]), "-I", str(copy), "--smiles", m["smiles"],
                   "--n", str(m["n_mol"]), "--density", repr(PACK_DENSITY),
                   "--seed", str(seed), "--out", str(out)]
            t0 = time.time()
            with tempfile.TemporaryDirectory(prefix="cp1_build_") as cwd:
                proc = subprocess.run(cmd, cwd=cwd, env=env, capture_output=True, text=True)
            ok = proc.returncode == 0 and (out / "in.data").exists() \
                and (out / "metadata.json").exists()
            meta = parse_metadata((out / "metadata.json").read_text()) if ok else {}
            apm = atoms_per_molecule(m["smiles"])
            counts_ok = ok and meta.get("n_molecules") == m["n_mol"] and \
                meta.get("atoms_per_molecule") == apm and \
                round(TARGET_ATOMS / apm) == m["n_mol"]
            decision = "PASS" if (ok and counts_ok) else "FAIL"
            if decision == "FAIL":
                failed.append(out.name)
            write_record(pre, cell={"stage": "prelaunch", "step": "build",
                                    "molecule": m["key"], "pack_seed": seed},
                         inputs=[describe(copy)], metric="packed box from the committed builder",
                         values={"command": cmd, "exit_code": proc.returncode,
                                 "seconds": time.time() - t0, "stdout": proc.stdout[-20000:],
                                 "stderr": proc.stderr[-20000:], "metadata": meta,
                                 "atoms_per_molecule_from_formula": apm,
                                 "molecules_expected": m["n_mol"],
                                 "packing_density": PACK_DENSITY},
                         threshold={"n_molecules": m["n_mol"], "packing_density": PACK_DENSITY},
                         decision_rule="the builder must exit cleanly, write the box, and "
                                       "report the design's molecule count; if Packmol cannot "
                                       "pack any box at 0.75 g/cm3, stop before launch",
                         decision=decision, rows=[{"line": ln} for ln in
                                                  proc.stdout.splitlines()[-200:]])
            print(f"[build] {out.name}: {decision} ({time.time() - t0:.0f}s)")
    if failed:
        return _fail(pre, f"box building failed for {failed}; no partial set is launched")
    return 0


def prelaunch_charge(pre: Path, systems: Path) -> int:
    if not step_passed(pre, "build", 24):
        return _fail(pre, "charge check needs all 24 boxes built")
    bad = []
    for m in MOLECULES:
        for r in RERUNS:
            seed = PACK_SEED_BASE + r - 1
            d = systems / system_dirname(m["key"], seed)
            meta = parse_metadata((d / "metadata.json").read_text())
            q = float(meta["net_charge_per_molecule"])
            ok = abs(q) <= CHARGE_TOLERANCE
            if not ok:
                bad.append(d.name)
            write_record(pre, cell={"stage": "prelaunch", "step": "charge",
                                    "molecule": m["key"], "pack_seed": seed},
                         inputs=[describe(d / "metadata.json")],
                         metric="net charge per molecule from the builder's metadata",
                         values={"net_charge_per_molecule": q},
                         threshold={"abs_max": CHARGE_TOLERANCE},
                         decision_rule="near zero means at most 1e-6 elementary charges "
                                       "(runner-chosen; the builder rounds to 1e-10)",
                         decision="PASS" if ok else "FAIL")
    return _fail(pre, f"net charge not near zero for {bad}") if bad else 0


def prelaunch_zerostep(pre: Path, systems: Path, toolchain: Path) -> int:
    if not step_passed(pre, "charge", 24):
        return _fail(pre, "zero-step read needs the charge check passed")
    tc = toolchain_paths(toolchain)
    if not tc["lmp"].exists():
        raise StageFailure(f"local simulation program missing at {tc['lmp']}")
    bad = []
    for m in MOLECULES:
        for r in RERUNS:
            seed = PACK_SEED_BASE + r - 1
            d = systems / system_dirname(m["key"], seed)
            wd = pre / "zerostep" / d.name
            wd.mkdir(parents=True, exist_ok=True)
            script = wd / "zero_step.in"
            script.write_text(zero_step_script(d.resolve()))
            logp = wd / "log_zero_step.out"
            proc = subprocess.run([str(tc["lmp"]), "-log", str(logp), "-screen", "none",
                                   "-in", str(script)], cwd=wd, capture_output=True, text=True)
            text = logp.read_text() if logp.exists() else ""
            log = parse_lammps_log(text)
            dens = None
            if log["blocks"] and log["blocks"][0]["rows"]:
                b = log["blocks"][0]
                row0 = [r_ for r_ in b["rows"] if int(r_[0]) == 0]
                if row0:
                    dens = row0[0][log_column(b, "Density")]
            ok = proc.returncode == 0 and not log["errors"] and dens is not None
            if not ok:
                bad.append(d.name)
            write_record(pre, cell={"stage": "prelaunch", "step": "zerostep",
                                    "molecule": m["key"], "pack_seed": seed},
                         inputs=[describe(d / "in.data")],
                         metric="zero-step read with the local simulation program",
                         values={"exit_code": proc.returncode, "density_step0": dens,
                                 "errors": log["errors"], "warnings": log["warnings"][:20]},
                         threshold={}, decision_rule="the box must load and report a "
                                                     "step-0 density with no error line",
                         decision="PASS" if ok else "FAIL",
                         rows=[{"line": ln} for ln in text.splitlines()])
    return _fail(pre, f"zero-step read failed for {bad}") if bad else 0


def prelaunch_density(pre: Path, systems: Path) -> int:
    if not step_passed(pre, "zerostep", 24):
        return _fail(pre, "the hand density check needs every zero-step read passed")
    zs = {(r["cell"]["molecule"], r["cell"]["pack_seed"]): r["values"]["density_step0"]
          for r in load_records(pre, "prelaunch") if r["cell"].get("step") == "zerostep"}
    bad = []
    for m in MOLECULES:
        for r in RERUNS:
            seed = PACK_SEED_BASE + r - 1
            d = systems / system_dirname(m["key"], seed)
            parsed = parse_data_file((d / "in.data").read_text())
            hand = hand_density(parsed)
            lmp_d = zs[(m["key"], seed)]
            rel = abs(hand / lmp_d - 1.0)
            ok = rel <= I2_TOLERANCE
            if not ok:
                bad.append(d.name)
            write_record(pre, cell={"stage": "prelaunch", "step": "density",
                                    "molecule": m["key"], "pack_seed": seed},
                         inputs=[describe(d / "in.data", parsed["atoms"])],
                         metric="density by hand from the data file against the program's "
                                "step-0 density (gate item I2)",
                         values={"hand_density": hand, "program_density_step0": lmp_d,
                                 "relative_difference": rel, "atoms": parsed["atoms"],
                                 "box": parsed["box"]},
                         threshold={"relative_max": I2_TOLERANCE},
                         decision_rule="hand density must match the step-0 density within "
                                       "0.1%; a mismatch stops the run before launch",
                         decision="PASS" if ok else "FAIL")
    return _fail(pre, f"hand density mismatch for {bad}") if bad else 0


def run_planted(pre: Path, *, quick: bool = False) -> dict:
    """The planted known-truth check (a)-(d) and the queued planted controls.

    numpy is needed here. All random draws come from one generator seeded 7,
    used in this order: (a), (b), (c), the 1.8 ns check, the cross-check.
    """
    import numpy as np
    rng = np.random.default_rng(PLANTED_SEED)
    mm = {k: molar_mass(MOL[k]["smiles"]) for k in KEYS}
    chosen = {k: planted_d_a2ps(MOL[k]["ref_eta"], MOL[k]["paper_rho"], mm[k]) for k in KEYS}
    n_bias = 2 if quick else N_BIAS_PER_MOLECULE
    n_band = 16 if quick else N_BAND
    n_sub = 16 if quick else N_SUBDIFF
    n_frames = int(round((D_WINDOW_PS[1] - D_WINDOW_PS[0]) / FRAME_PS)) + 1
    out = {"chosen_D_A2_per_ps": chosen, "ensembles": {}}

    # (a) and the alternative windows (gate item I10), and the rerun sets (I8)
    est = {w: [] for w in LAG_WINDOWS_PS}
    truth = []
    per_mol_main = {k: [] for k in KEYS}
    t0 = time.time()
    for k in KEYS:
        for _ in range(n_bias):
            arr = gen_brownian(rng, MOL[k]["n_mol"], n_frames, chosen[k])
            res = analyse_window(None, MOL[k]["n_mol"], LAG_WINDOWS_PS, use_numpy=True,
                                 positions=arr)
            for w in LAG_WINDOWS_PS:
                est[w].append(res["D"][w])
            truth.append(chosen[k])
            per_mol_main[k].append(res["D"]["main"])
    out["a_bias_main"] = bias_test(est["main"], truth)
    out["i10_bias_early"] = bias_test(est["early"], truth)
    out["i10_bias_late"] = bias_test(est["late"], truth)
    out["ensembles"]["a"] = len(truth)
    print(f"[planted] (a) and alternative windows: {len(truth)} ensembles, "
          f"{time.time() - t0:.0f}s")

    # (b) slope band from ordinary walks
    slopes_b = []
    for j in range(n_band):
        k = KEYS[j % len(KEYS)]
        arr = gen_brownian(rng, MOL[k]["n_mol"], n_frames, chosen[k])
        res = analyse_window(None, MOL[k]["n_mol"], {"main": LAG_WINDOWS_PS["main"]},
                             use_numpy=True, positions=arr)
        slopes_b.append(res["slope"]["main"])
    half = slope_band(slopes_b)
    inside_b = sum(1 for s in slopes_b if not outside_band(s, half)) / len(slopes_b)

    # (c) walks whose MSD grows as lag**0.7
    slopes_c = []
    for j in range(n_sub):
        k = KEYS[j % len(KEYS)]
        arr = gen_power_law(rng, MOL[k]["n_mol"], n_frames, chosen[k], SUBDIFF_EXPONENT)
        res = analyse_window(None, MOL[k]["n_mol"], {"main": LAG_WINDOWS_PS["main"]},
                             use_numpy=True, positions=arr)
        slopes_c.append(res["slope"]["main"])
    outside_c = sum(1 for s in slopes_c if outside_band(s, half)) / len(slopes_c)
    out["b_band_half_width"] = half
    out["b_fraction_inside"] = inside_b
    out["c_fraction_outside"] = outside_c
    out["b_slopes"] = slopes_b
    out["c_slopes"] = slopes_c
    out["bc_passed"] = inside_b >= BAND_FRACTION - 1e-12 and outside_c >= BAND_FRACTION - 1e-12

    # (d) every decision label reachable through the real decision functions
    ref_eta = [MOL[k]["ref_eta"] for k in KEYS]
    prox_known = [proxy_mpas(planted_d_a2ps(MOL[k]["ref_eta"], MOL[k]["paper_rho"], mm[k]),
                             MOL[k]["paper_rho"], mm[k]) for k in KEYS]
    rho_known = spearman(prox_known, ref_eta)
    rho_rev = spearman([1.0 / p for p in prox_known], ref_eta)
    d_known = main_decision(rho_known)[0]
    d_rev = main_decision(rho_rev)[0]
    dens_ok = {k: MOL[k]["paper_rho"] for k in KEYS}
    dens_off = dict(dens_ok)
    dens_off[GLYCOL_KEY] = MOL[GLYCOL_KEY]["paper_rho"] * DENSITY_OFF_FACTOR
    gate_ok = density_gate(dens_ok)["passed"]
    gate_off = density_gate(dens_off)["passed"]
    nondiff_reached = any(outside_band(s, half) for s in slopes_c)
    out["d"] = {"rho_known": rho_known, "rho_reversed": rho_rev, "known_decision": d_known,
                "reversed_decision": d_rev, "gate_with_paper_densities": gate_ok,
                "gate_with_one_density_5pct_off": gate_off,
                "labels_reached": {"gate fail": not gate_off,
                                   "non-diffusive": nondiff_reached,
                                   "main pass": d_known == "PASS",
                                   "main refuted": d_rev.startswith("REFUTED")}}
    out["d_passed"] = (abs(rho_known - 1) < 1e-12 and abs(rho_rev + 1) < 1e-12 and gate_ok
                       and all(out["d"]["labels_reached"].values()))

    # Gate item I8: margin halt and pick counts
    sets3 = {k: per_mol_main[k][:3] for k in KEYS}
    sets2 = {k: per_mol_main[k][:2] for k in KEYS}
    same3 = {k: [per_mol_main[k][0]] * 3 for k in KEYS}
    i8 = {}
    if not quick:
        m3 = added_value_margin(sets3, dens_ok, _planted_ref(mm))
        i8["three_reruns"] = m3
    m2 = added_value_margin(sets2, dens_ok, _planted_ref(mm))
    i8["two_reruns"] = m2
    try:
        added_value_margin(same3, dens_ok, _planted_ref(mm))
        i8["identical_reruns"] = "no halt"
    except WrongVarianceSource:
        i8["identical_reruns"] = WRONG_VARIANCE
    i8["passed"] = (i8["identical_reruns"] == WRONG_VARIANCE and m2["n_picks"] == 256
                    and m2["margin"] > 0
                    and (quick or (i8["three_reruns"]["n_picks"] == 6561
                                   and i8["three_reruns"]["margin"] > 0)))
    out["i8"] = i8

    # Gate item I5, planted part: 1.8 ns window split into two files at 1.0 ns
    long_frames = int(round(LONG_WINDOW_PS[1] / FRAME_PS)) + 1
    every = int(round(FRAME_PS * 1000.0 / MAIN_DT_FS))
    join_step = int(round(JOIN_PS * 1000.0 / MAIN_DT_FS))
    est5, truth5, dup = [], [], 0.0
    t0 = time.time()
    with tempfile.TemporaryDirectory(prefix="cp1_i5_") as td:
        for k in KEYS:
            for _ in range(n_bias):
                n = MOL[k]["n_mol"]
                arr = gen_brownian(rng, n, long_frames, chosen[k])
                frames = numpy_to_frames(arr)
                steps = [i * every for i in range(long_frames)]
                half_i = int(round(JOIN_PS / FRAME_PS))
                p1 = Path(td) / "main.dat"
                p2 = Path(td) / "ext.dat"
                p1.write_text(format_ave_time_vector(steps[:half_i + 1], frames[:half_i + 1]))
                p2.write_text(format_ave_time_vector(steps[half_i:], frames[half_i:]))
                ms, mf = parse_ave_time_vector(p1.read_text(), n)
                es, ef = parse_ave_time_vector(p2.read_text(), n)
                js, jf, info = join_extension(ms, mf, es, ef, join_step)
                dup = max(dup, info["duplicate_frame_max_abs_diff_A"])
                ws, wf = select_window(js, jf, MAIN_DT_FS, LONG_WINDOW_PS)
                if detect_grid(ws, MAIN_DT_FS, LONG_WINDOW_PS):
                    raise StageFailure("planted 1.8 ns window failed its grid check")
                res = analyse_window(wf, n, {"long": LONG_LAGS_PS}, use_numpy=True)
                est5.append(res["D"]["long"])
                truth5.append(chosen[k])
    out["i5_bias_long"] = bias_test(est5, truth5)
    out["i5_duplicate_frame_max_abs_diff_A"] = dup
    out["i5_passed"] = out["i5_bias_long"]["passed"]
    print(f"[planted] 1.8 ns split check: {len(truth5)} ensembles, {time.time() - t0:.0f}s")

    # Cross-check of the fast path against the plain path (code integrity)
    small = gen_brownian(rng, 7, 60, 0.05)
    fr = numpy_to_frames(small)
    lags = list(range(1, 30))
    a = msd_py(remove_drift_py(fr, 7), 7, lags)
    arr = small - small.mean(axis=1, keepdims=True)
    b = msd_numpy(arr, lags)
    worst = max(abs(a[m] - b[m]) / a[m] for m in lags)
    out["numpy_crosscheck_worst_relative_difference"] = worst
    out["numpy_crosscheck_passed"] = worst <= 1e-9

    out["i3"] = planted_proxy_check()
    out["i7"] = planted_family_check()
    out["a_passed"] = out["a_bias_main"]["passed"]
    out["i10_passed"] = out["i10_bias_early"]["passed"] and out["i10_bias_late"]["passed"]
    out["r1_passed"] = out["a_passed"] and out["bc_passed"] and out["d_passed"]
    out["passed"] = all([out["r1_passed"], out["i3"]["passed"], out["i5_passed"],
                         out["i7"]["passed"], out["i8"]["passed"], out["i10_passed"],
                         out["numpy_crosscheck_passed"]])
    return out


def _planted_ref(mm: dict) -> dict:
    return {k: {"eta": MOL[k]["ref_eta"], "molar_mass": mm[k]} for k in KEYS}


def prelaunch_planted(pre: Path) -> int:
    """R1 and the planted controls, with the local numpy (directive (b) step 5)."""
    out = run_planted(pre)
    parts = [
        ("planted-a", "recovered-D bias on ordinary walks, main window",
         out["a_bias_main"], out["a_passed"]),
        ("planted-bc", "slope band from ordinary walks; power-law walks outside it",
         {"half_width": out["b_band_half_width"], "fraction_inside": out["b_fraction_inside"],
          "fraction_outside_power_law": out["c_fraction_outside"]}, out["bc_passed"]),
        ("planted-d", "known, reversed and off-density inputs reach every label",
         out["d"], out["d_passed"]),
        ("planted-i3", "planted proxy path (gate item I3)", out["i3"], out["i3"]["passed"]),
        ("planted-i5", "planted 1.8 ns window split at 1.0 ns (gate item I5)",
         {"bias": out["i5_bias_long"], "duplicate_frame_max_abs_diff_A":
          out["i5_duplicate_frame_max_abs_diff_A"]}, out["i5_passed"]),
        ("planted-i7", "planted family orderings (gate item I7)", out["i7"],
         out["i7"]["passed"]),
        ("planted-i8", "margin halt and pick counts (gate item I8)", out["i8"],
         out["i8"]["passed"]),
        ("planted-i10", "planted bias at the two other lag windows (gate item I10)",
         {"early": out["i10_bias_early"], "late": out["i10_bias_late"]}, out["i10_passed"]),
        ("planted-crosscheck", "fast and plain displacement code agree",
         {"worst_relative_difference": out["numpy_crosscheck_worst_relative_difference"]},
         out["numpy_crosscheck_passed"]),
    ]
    for name, metric, vals, ok in parts:
        write_record(pre, cell={"stage": "prelaunch", "step": "planted", "check": name},
                     inputs=[], metric=metric, values=vals,
                     threshold={"bias_standard_errors": BIAS_SE_MULT,
                                "band_fraction": BAND_FRACTION, "seed": PLANTED_SEED},
                     decision_rule="planted known truth: each check must pass before any "
                                   "real result is read; a failure stops the run before launch",
                     decision="PASS" if ok else "FAIL")
    write_record(pre, cell={"stage": "prelaunch", "step": "planted", "check": "summary"},
                 inputs=[], metric="planted known-truth check and queued planted controls",
                 values={"r1_passed": out["r1_passed"], "slope_band_half_width":
                         out["b_band_half_width"], "passed": out["passed"],
                         "chosen_D_A2_per_ps": out["chosen_D_A2_per_ps"]},
                 threshold={}, decision_rule="every planted part must pass",
                 decision="PASS" if out["passed"] else "FAIL",
                 rows=[{"set": "b", "slope": s} for s in out["b_slopes"]] +
                      [{"set": "c", "slope": s} for s in out["c_slopes"]])
    return 0 if out["passed"] else _fail(pre, "a planted known-truth check failed")


def prelaunch_manifest(root: Path, pre: Path, systems: Path, toolchain: Path) -> int:
    """Step 6: hash every built file and record every tool version."""
    needed = {"precheck": 1, "build": 24, "charge": 24, "zerostep": 24, "density": 24}
    for step, n in needed.items():
        if not step_passed(pre, step, n):
            return _fail(pre, f"manifest refused: step {step} has not passed")
    planted = [r for r in load_records(pre, "prelaunch") if r["cell"].get("step") == "planted"]
    if not planted or not all(r["decision"] == "PASS" and r["run_valid"] for r in planted):
        return _fail(pre, "manifest refused: the planted checks have not all passed")
    summ = [r for r in planted if r["cell"].get("check") == "summary"][0]
    pre_rec = [r for r in load_records(pre, "prelaunch") if r["cell"].get("step") == "precheck"][0]
    tc = toolchain_paths(toolchain)
    help_text = subprocess.run([str(tc["lmp"]), "-h"], capture_output=True, text=True).stdout
    lh = parse_lmp_help(help_text)
    syslist = []
    for m in MOLECULES:
        for r in RERUNS:
            seed = PACK_SEED_BASE + r - 1
            d = systems / system_dirname(m["key"], seed)
            meta = parse_metadata((d / "metadata.json").read_text())
            syslist.append({"molecule": m["key"], "pack_seed": seed, "dir": d.name,
                            "n_molecules": meta["n_molecules"],
                            "atoms_per_molecule": meta["atoms_per_molecule"],
                            "files": {f: sha256_file(d / f) for f in
                                      ("in.data", "in.init", "in.settings", "metadata.json")}})
    manifest = {
        "schema": "cp1_box_manifest_v1", "created_utc": utc_now(),
        "prelaunch_passed": True,
        "steps": {s: "PASS" for s in PRELAUNCH_STEPS if s != "manifest"},
        "endpoint1": pre_rec["values"], "planted_summary": summ["values"],
        "slope_band_half_width": summ["values"]["slope_band_half_width"],
        "packing_density": PACK_DENSITY, "systems": syslist,
        "committed_hashes": {k: v[1] for k, v in COMMITTED.items()},
        "binding_texts": SPEC,
        "tool_versions": {"local_lammps_help_release": lh["version"],
                          "conda": conda_versions(tc["meta"], {"lammps", "rdkit", "packmol",
                                                               "numpy", "python", "openmpi"}),
                          "runner_python": sys.version.split()[0]},
    }
    fsync_write(systems / "box_manifest.json", json.dumps(manifest, indent=2, sort_keys=True))
    write_record(pre, cell={"stage": "prelaunch", "step": "manifest"},
                 inputs=[describe(systems / "box_manifest.json", len(syslist))],
                 metric="hash of every built box file and every tool version",
                 values={"systems": len(syslist), "tool_versions": manifest["tool_versions"],
                         "manifest_sha256": sha256_file(systems / "box_manifest.json")},
                 threshold={"systems": 24}, decision_rule="written only when every earlier "
                                                         "pre-launch step passed",
                 decision="PASS" if len(syslist) == 24 else "FAIL",
                 rows=syslist)
    print(f"[manifest] {systems / 'box_manifest.json'}")
    return 0


def stage_prelaunch(args) -> int:
    root = Path(args.root)
    pre = prelaunch_dir(args.results)
    pre.mkdir(parents=True, exist_ok=True)
    ensure_run_state(pre)
    if not read_run_state(pre)["run_valid"]:
        print("[prelaunch] this pre-launch folder is already void; start a fresh one")
        return 1
    systems = Path(args.systems) if args.systems else pre / "systems"
    toolchain = Path(args.toolchain)
    steps = [args.step] if args.step else PRELAUNCH_STEPS
    for s in steps:
        print(f"[prelaunch] step {s} ({utc_now()})")
        if s == "precheck":
            rc = prelaunch_precheck(root, pre)
        elif s == "build":
            rc = prelaunch_build(root, pre, toolchain, systems)
        elif s == "charge":
            rc = prelaunch_charge(pre, systems)
        elif s == "zerostep":
            rc = prelaunch_zerostep(pre, systems, toolchain)
        elif s == "density":
            rc = prelaunch_density(pre, systems)
        elif s == "planted":
            rc = prelaunch_planted(pre)
        elif s == "manifest":
            rc = prelaunch_manifest(root, pre, systems, toolchain)
        else:
            raise StageFailure(f"unknown pre-launch step {s}")
        if rc:
            return rc
    return 0

def load_manifest(systems: Path) -> dict:
    p = Path(systems) / "box_manifest.json"
    if not p.exists():
        raise StageFailure(f"no box manifest at {p}; the pre-launch steps did not finish")
    man = json.loads(p.read_text())
    if man.get("schema") != "cp1_box_manifest_v1" or man.get("prelaunch_passed") is not True:
        raise StageFailure("the box manifest does not record a passed pre-launch")
    return man


def accel_candidates(help_info: dict) -> list:
    pk = set(help_info["packages"])
    acc = " ".join(help_info["accelerator_lines"])
    cands = []
    if "GPU" in pk:
        cands.append(("gpu-package", ["-sf", "gpu", "-pk", "gpu", "1"]))
        cands.append(("gpu-package-host-neighbor", ["-sf", "gpu", "-pk", "gpu", "1",
                                                    "neigh", "no"]))
    if "KOKKOS" in pk and "CUDA" in acc.upper():
        cands.append(("kokkos-cuda", ["-k", "on", "g", "1", "-sf", "kk"]))
    return cands


def accel_evidence(path_name: str, text: str) -> list:
    lines = [ln.strip() for ln in text.splitlines()]
    if path_name.startswith("gpu-package"):
        hits = [ln for ln in lines if "Using acceleration for" in ln or ln.startswith("Device ")]
        return hits if any("Using acceleration for" in h for h in hits) else []
    if path_name.startswith("kokkos"):
        hits = [ln for ln in lines if "KOKKOS mode" in ln or "GPU(s) per node" in ln]
        ok = any("KOKKOS mode" in h for h in hits) and \
            any(re.search(r"use up to\s+[1-9]\d*\s+GPU", h) for h in hits)
        return hits if ok else []
    return []


def ranks_per_run() -> int:
    return max(1, (os.cpu_count() or 4) // WAVE_SIZE)


def smoke_test(name, accel, sys_dir: Path, work: Path, lmp, mpirun, ranks) -> dict:
    d = work / f"smoke_{name}"
    if d.exists():
        shutil.rmtree(d)
    d.mkdir(parents=True)
    for f in ("in.init", "in.data", "in.settings"):
        shutil.copyfile(sys_dir / f, d / f)
    deck = d / "deck_used.in"
    deck.write_text(edit_main_deck(check_committed(HERE, "deck").read_text()))
    ext = d / "extension_used.in"
    ext.write_text(extension_deck_text())
    res = {"path": name, "switches": accel}
    t0 = time.time()
    cmd = lmp_command(mpirun, ranks, lmp, accel, deck, smoke_vars(d))
    try:
        p = subprocess.run(cmd, cwd=d, capture_output=True, text=True,
                           timeout=SMOKE_TIMEOUT_SECONDS)
        rc, out = p.returncode, p.stdout + p.stderr
    except subprocess.TimeoutExpired as e:
        rc, out = "timeout", (e.stdout or "") if isinstance(e.stdout, str) else ""
    logp = d / main_log_name(1)
    logtext = logp.read_text() if logp.exists() else ""
    log = parse_lammps_log(logtext)
    res["main"] = {"exit_code": rc, "seconds": time.time() - t0, "errors": log["errors"][:10],
                   "done": bool(log["done_lines"])}
    ok_main = rc == 0 and bool(log["done_lines"]) and not log["errors"]
    ok_ext = False
    if ok_main:
        t1 = time.time()
        ev = extension_vars(d, d, d / RESTART_NAME, 1)
        ev[ev.index("ext_steps") + 1] = "200"
        ev[ev.index("com_every") + 1] = "100"
        cmd2 = lmp_command(mpirun, ranks, lmp, accel, ext, ev)
        try:
            p2 = subprocess.run(cmd2, cwd=d, capture_output=True, text=True,
                                timeout=SMOKE_TIMEOUT_SECONDS)
            rc2, out2 = p2.returncode, p2.stdout + p2.stderr
        except subprocess.TimeoutExpired:
            rc2, out2 = "timeout", ""
        elog = parse_lammps_log((d / ext_log_name(1)).read_text()
                                if (d / ext_log_name(1)).exists() else "")
        ok_ext = rc2 == 0 and bool(elog["done_lines"]) and not elog["errors"]
        res["extension"] = {"exit_code": rc2, "seconds": time.time() - t1,
                            "errors": elog["errors"][:10]}
        out += "\n" + out2
    ev_lines = accel_evidence(name, out + "\n" + logtext) if name != "cpu" else []
    res["evidence_lines"] = ev_lines[:20]
    res["ok"] = ok_main and ok_ext and (name == "cpu" or bool(ev_lines))
    (d / "stdout_smoke.txt").write_text(out)
    return res


def stage_engine(args) -> int:
    results = Path(args.results)
    ensure_run_state(results)
    work = Path(args.work)
    work.mkdir(parents=True, exist_ok=True)
    man = load_manifest(Path(args.systems))
    lmp = Path(args.lmp)
    mpirun = Path(args.mpirun) if args.mpirun else None
    help_text = subprocess.run([str(lmp), "-h"], capture_output=True, text=True).stdout
    lh = parse_lmp_help(help_text)
    first = man["systems"][0]
    sys_dir = Path(args.systems) / first["dir"]
    ranks = ranks_per_run()
    tried = []
    chosen = None
    if lh["version"] != "29 Aug 2024":
        tried.append({"path": "none", "ok": False,
                      "note": f"release is {lh['version']!r}, not 29 Aug 2024"})
    else:
        for name, accel in accel_candidates(lh):
            r = smoke_test(name, accel, sys_dir, work, lmp, mpirun, ranks)
            tried.append(r)
            print(f"[engine] {name}: {'ok' if r['ok'] else 'failed'}")
            if r["ok"]:
                chosen = r
                break
        if chosen is None:
            r = smoke_test("cpu", [], sys_dir, work, lmp, mpirun, ranks)
            tried.append(r)
            print(f"[engine] processor fallback: {'ok' if r['ok'] else 'failed'}")
            if r["ok"]:
                chosen = r
    versions = {"lammps_release": lh["version"], "lammps_packages": lh["packages"],
                "accelerator_lines": lh["accelerator_lines"],
                "python": sys.version.split()[0], "cpu_count": os.cpu_count(),
                "ranks_per_run": ranks}
    try:
        import numpy
        versions["numpy"] = numpy.__version__
    except Exception as e:
        versions["numpy"] = f"unavailable: {e}"
    if args.env_prefix:
        versions["conda"] = conda_versions(Path(args.env_prefix) / "conda-meta",
                                           {"lammps", "numpy", "python", "openmpi", "fftw",
                                            "cuda-version", "cuda-cudart"})
    try:
        versions["gpus"] = subprocess.run(["nvidia-smi", "-L"], capture_output=True,
                                          text=True, timeout=60).stdout.strip()
    except Exception as e:
        versions["gpus"] = f"nvidia-smi unavailable: {e}"
    versions["lambda_instance_id"] = os.environ.get("LAMBDA_INSTANCE_ID", "")
    versions["git_commit"] = os.environ.get("GIT_COMMIT", "")
    path = None if chosen is None else ("gpu" if chosen["path"] != "cpu" else "cpu")
    write_record(results, cell={"stage": "engine", "event": "acceleration"},
                 inputs=[], metric="which acceleration path ran, and every tool version",
                 values={"chosen_path": chosen["path"] if chosen else None,
                         "acceleration": path, "switches": chosen["switches"] if chosen else None,
                         "ranks_per_run": ranks, "trials": tried, "tool_versions": versions},
                 threshold={}, decision_rule="the first GPU switch set whose short trial "
                 "finishes both decks with GPU evidence in the log is used; if none works, "
                 "the processor path is used; if that fails too, the run stops",
                 decision=("GPU" if path == "gpu" else "CPU") if chosen else "FAIL")
    if chosen is None:
        void_run(results, "the simulation program could not run on this box")
        return 1
    return 0


def stage_verify(args) -> int:
    results = Path(args.results)
    ensure_run_state(results)
    systems = Path(args.systems)
    problems = []
    hashes = {}
    try:
        man = load_manifest(systems)
    except StageFailure as e:
        man = None
        problems.append(str(e))
    if man:
        want = {(m["key"], PACK_SEED_BASE + r - 1) for m in MOLECULES for r in RERUNS}
        have = {(s["molecule"], s["pack_seed"]) for s in man["systems"]}
        if want != have or len(man["systems"]) != 24:
            problems.append("the manifest does not list exactly the 24 boxes")
        for s in man["systems"]:
            for f, h in s["files"].items():
                p = systems / s["dir"] / f
                got = sha256_file(p) if p.exists() else None
                hashes[f"{s['dir']}/{f}"] = got
                if got != h:
                    problems.append(f"{s['dir']}/{f}: expected {h}, got {got}")
    for name in ("deck", "dataset", "predictions"):
        try:
            check_committed(HERE, name)
            hashes[COMMITTED[name][0]] = COMMITTED[name][1]
        except StageFailure as e:
            problems.append(str(e))
    write_record(results, cell={"stage": "verify", "event": "box-hashes"},
                 inputs=[describe(systems / "box_manifest.json")],
                 metric="sha256 of every shipped box file against the pre-launch record",
                 values={"hashes": hashes, "problems": problems,
                         "slope_band_half_width": man and man.get("slope_band_half_width")},
                 threshold={}, decision_rule="every shipped file must match its recorded "
                                             "hash; any mismatch stops the run",
                 decision="PASS" if not problems else "FAIL")
    if problems:
        for p in problems[:20]:
            print(f"[verify] {p}")
        void_run(results, "a shipped file did not match its pre-launch hash")
        return 1
    return 0

def latest_record(results: Path, stage: str, event: str):
    recs = [r for r in load_records(results, stage) if r["cell"].get("event") == event]
    return recs[-1] if recs else None


class Running:
    def __init__(self, spec: RunSpec, proc, run_dir: Path, t0: float, up0: float, cmd):
        self.spec, self.proc, self.run_dir, self.t0, self.up0, self.cmd = \
            spec, proc, run_dir, t0, up0, cmd
        self.ended = None
        self.status = None
        self.stopped_reason = None


def kill_group(proc) -> None:
    try:
        os.killpg(proc.pid, signal.SIGTERM)
    except Exception:
        return
    t = time.time()
    while time.time() - t < KILL_GRACE_SECONDS:
        if proc.poll() is not None:
            return
        time.sleep(1)
    try:
        os.killpg(proc.pid, signal.SIGKILL)
    except Exception:
        pass
    proc.wait()


class Generator:
    def __init__(self, args):
        self.results = Path(args.results)
        self.work = Path(args.work)
        self.systems = Path(args.systems)
        self.lmp = Path(args.lmp)
        self.mpirun = Path(args.mpirun) if args.mpirun else None
        self.manifest = load_manifest(self.systems)
        self.limit = time_limit(os.environ.get("PRICE_USD_PER_HOUR"),
                                os.environ.get("BUDGET_LEFT_USD"))
        self.T = self.limit["time_limit_hours"]
        eng = latest_record(self.results, "engine", "acceleration")
        ver = latest_record(self.results, "verify", "box-hashes")
        if not eng or eng["decision"] == "FAIL":
            raise StageFailure("no working engine path is recorded; run the engine stage")
        if not ver or ver["decision"] != "PASS":
            raise StageFailure("the box hashes have not been verified")
        self.accel = eng["values"]["switches"] or []
        self.accel_path = eng["values"]["acceleration"]
        self.ranks = eng["values"]["ranks_per_run"]
        self.main_deck = edit_main_deck(check_committed(HERE, "deck").read_text())
        self.ext_deck = extension_deck_text()
        misses = check_extension_lines(check_committed(HERE, "deck").read_text())
        if misses:
            raise StageFailure(f"continuation deck lines not in the committed deck: {misses}")
        self.ok_slugs = {}
        self.waves = []
        self.durations = []
        self.stop_reason = None
        self.probe = None
        self.tier_status = {}

    def system_dir(self, spec: RunSpec) -> Path:
        return self.systems / system_dirname(spec.molecule, spec.pack_seed)

    def prepare(self, spec: RunSpec):
        rd = self.work / spec.slug
        if rd.exists():
            shutil.rmtree(rd)
        rd.mkdir(parents=True)
        if spec.kind in ("main", "timestep1fs"):
            for f in ("in.init", "in.data", "in.settings"):
                shutil.copyfile(self.system_dir(spec) / f, rd / f)
            deck = rd / "deck_used.in"
            deck.write_text(self.main_deck)
            vars_list = main_run_vars(rd, spec.rerun, spec.timestep_fs)
        else:
            parent = self.ok_slugs.get((spec.molecule, 1, "main"))
            if parent is None:
                raise StageFailure(f"no finished rerun 1 to extend for {spec.molecule}")
            for f in ("in.init", "in.settings"):
                shutil.copyfile(self.system_dir(spec) / f, rd / f)
            deck = rd / "deck_used.in"
            deck.write_text(self.ext_deck)
            vars_list = extension_vars(rd, rd, self.work / parent / RESTART_NAME, spec.rerun)
        cmd = lmp_command(self.mpirun, self.ranks, self.lmp, self.accel, deck, vars_list)
        fsync_write(rd / "command.json", json.dumps({"command": cmd}, indent=2))
        return rd, cmd

    def start(self, spec: RunSpec) -> Running:
        rd, cmd = self.prepare(spec)
        out = open(rd / "stdout.txt", "w")
        env = dict(os.environ, OMP_NUM_THREADS="1")
        proc = subprocess.Popen(cmd, cwd=rd, stdout=out, stderr=subprocess.STDOUT,
                                start_new_session=True, env=env)
        out.close()
        return Running(spec, proc, rd, time.time(), uptime_hours() * 3600.0, cmd)

    def finalize(self, run: Running, runs_in_wave: int, wave_no: int) -> str:
        spec = run.spec
        raw = self.results / "cells" / spec.slug
        raw.mkdir(parents=True, exist_ok=True)
        rd = run.run_dir
        names = ["stdout.txt", "deck_used.in", "command.json"]
        if spec.kind == "extension":
            names += [ext_log_name(spec.rerun)]
            gz = [ext_com_name(spec.rerun)]
        else:
            names += [main_log_name(spec.rerun), density_name(spec.rerun)]
            gz = [com_name(spec.rerun)]
        for n in names:
            if (rd / n).exists():
                shutil.copyfile(rd / n, raw / n)
        for n in gz:
            if (rd / n).exists():
                with open(rd / n, "rb") as src, gzip.open(raw / (n + ".gz"), "wb") as dst:
                    shutil.copyfileobj(src, dst)
        wall = (run.ended or time.time()) - run.t0
        parent = self.ok_slugs.get((spec.molecule, 1, "main")) if spec.kind == "extension" else None
        meta = {"molecule": spec.molecule, "rerun": spec.rerun, "kind": spec.kind,
                "attempt": spec.attempt, "tier": spec.tier, "timestep_fs": spec.timestep_fs,
                "n_molecules": MOL[spec.molecule]["n_mol"], "pack_seed": spec.pack_seed,
                "exit_code": run.proc.returncode, "wall_seconds": wall,
                "runs_in_wave": runs_in_wave, "wave": wave_no,
                "gpu_hours_share": wall / 3600.0 / runs_in_wave,
                "accel_path": self.accel_path, "steps": spec.steps, "command": run.cmd,
                "stopped_reason": run.stopped_reason, "parent_slug": parent,
                "started_uptime_s": run.up0}
        fsync_write(raw / "run_meta.json", json.dumps(meta, indent=2, sort_keys=True))
        try:
            out = record_cell(self.results, raw, meta, use_numpy=True)
            status = out["status"]
        except Exception as e:      # extraction trouble never kills the session
            status = "degenerate"
            write_record(self.results, cell=spec.cell, inputs=[],
                         metric="per-run density, mean-squared displacement and D",
                         values={"status": status, "flags": ["DEGENERATE_EXTRACTION_ERROR"],
                                 "error": repr(e), "molecule": spec.molecule,
                                 "rerun": spec.rerun, "kind": spec.kind},
                         threshold={}, decision_rule=CELL_RULE, decision="CELL_DEGENERATE")
        if status == "ok":
            self.ok_slugs[(spec.molecule, spec.rerun, spec.kind)] = spec.slug
        print(f"[cell] {spec.slug}: {status} ({wall:.0f}s)")
        return status

    def write_state(self):
        st = {"time_limit": self.limit, "waves": self.waves, "probe": self.probe,
              "stop_reason": self.stop_reason, "tiers": self.tier_status,
              "finished": sorted("|".join(map(str, k)) for k in self.ok_slugs)}
        fsync_write(self.results / "TIERS.json", json.dumps(st, indent=2, sort_keys=True))

    def probe_check(self, running: list, wave_t0: float) -> dict | None:
        prog = {}
        for r in running:
            if r.status in ("failed", "degenerate", "stopped"):
                continue
            logp = r.run_dir / main_log_name(r.spec.rerun)
            p = main_deck_progress(parse_lammps_log(logp.read_text())) if logp.exists() \
                else {"stage3_step": None, "steps_done": 0}
            if r.status == "ok":
                p = {"stage3_step": MAIN_NPT, "steps_done": r.spec.steps}
            prog[r.spec.slug] = p
        if not prog:
            return {"measured": False}
        if not all(p["stage3_step"] is not None and p["stage3_step"] >= PROBE_STAGE3_STEPS
                   for p in prog.values()):
            return None
        elapsed = time.time() - wave_t0
        total = sum(p["steps_done"] for p in prog.values())
        rate = total / elapsed if elapsed > 0 else 0.0
        up = uptime_hours()
        rule = probe_rule(up, rate, self.T)
        return {"measured": True, "per_run": prog, "wave_elapsed_seconds": elapsed,
                "steps_total": total, "combined_rate_steps_per_s": rate,
                "guessed_rate_steps_per_s": GUESSED_RATE,
                "measured_over_guessed": rate / GUESSED_RATE, "hours_used": up,
                "remaining_tier1_steps": PROBE_REMAINING_TIER1, "time_limit_hours": self.T,
                "spare_hours": SPARE_HOURS, **rule}

    def run_wave(self, specs: list, wave_no: int, do_probe: bool) -> dict:
        wave_t0 = time.time()
        running = [self.start(s) for s in specs]
        print(f"[wave {wave_no}] started {[s.slug for s in specs]}")
        probe_written = not do_probe
        stop = None
        while any(r.status is None for r in running):
            time.sleep(POLL_SECONDS)
            for r in running:
                if r.status is None and r.proc.poll() is not None:
                    r.ended = time.time()
                    r.status = self.finalize(r, len(specs), wave_no)
            if any(r.status is None for r in running) and uptime_hours() >= self.T:
                stop = "the time limit T was reached during a wave"
            if not probe_written:
                res = self.probe_check(running, wave_t0)
                if res is not None:
                    probe_written = True
                    self.probe = res
                    fits = res.get("fits", False) if res.get("measured") else True
                    write_record(self.results, cell={"stage": "generate", "event": "probe"},
                                 inputs=[], metric="throughput probe in wave 1 (gate item D5)",
                                 values=res,
                                 threshold={"limit_hours": self.T, "spare_hours": SPARE_HOURS,
                                            "remaining_tier1_steps": PROBE_REMAINING_TIER1},
                                 decision_rule="hours used plus 9.0 million steps at the "
                                               "measured rate must fit the time limit with 15 "
                                               "minutes spare; otherwise stop all runs",
                                 decision=("CONTINUE" if fits else "STOP_TIER1_CANNOT_FIT")
                                 if res.get("measured") else "NOT_MEASURED")
                    if not fits:
                        stop = ("throughput probe: tier 1 cannot finish within the time limit "
                                f"(measured {res['combined_rate_steps_per_s']:.1f} steps/s "
                                f"against the guessed {GUESSED_RATE:.0f})")
            if stop:
                for r in running:
                    if r.status is None:
                        r.stopped_reason = stop
                        kill_group(r.proc)
                        r.ended = time.time()
                        r.status = self.finalize(r, len(specs), wave_no)
                break
        if do_probe and not probe_written:
            res = self.probe_check(running, wave_t0) or {"measured": False}
            self.probe = res
            write_record(self.results, cell={"stage": "generate", "event": "probe"}, inputs=[],
                         metric="throughput probe in wave 1 (gate item D5)", values=res,
                         threshold={}, decision_rule="probe point not reached before the "
                                                     "wave ended; the clock rule guards later "
                                                     "waves", decision="NOT_MEASURED")
        dur = time.time() - wave_t0
        return {"wave": wave_no, "runs": [r.spec.slug for r in running],
                "statuses": {r.spec.slug: r.status for r in running},
                "seconds": dur, "stop": stop, "specs": running}

    def run(self) -> int:
        plan = plan_tiers()
        wave_no = 0
        write_record(self.results, cell={"stage": "generate", "event": "time-limit"}, inputs=[],
                     metric="price, budget and the runner time limit (directive (d))",
                     values=self.limit, threshold={"launch_min_hours": float(LAUNCH_MIN_HOURS)},
                     decision_rule="T = min(18.0/P, B/P - 0.75) hours from box boot",
                     decision="LIMIT_SET" if self.limit["launch_rule_met"]
                     else "LIMIT_SET_BELOW_LAUNCH_RULE")
        for tier in (1, 2, 3, 4):
            queue = list(plan[tier])
            self.tier_status[tier] = "running"
            while queue and self.stop_reason is None:
                specs, queue = queue[:WAVE_SIZE], queue[WAVE_SIZE:]
                wave_no += 1
                up = uptime_hours()
                rule = clock_rule(up, self.durations, self.T)
                write_record(self.results, cell={"stage": "generate", "event": "wave",
                                                 "wave": wave_no},
                             inputs=[], metric="clock rule before a wave",
                             values=dict(rule, tier=tier, runs=[s.slug for s in specs],
                                         uptime_hours=up, time_limit_hours=self.T),
                             threshold={"spare_hours": SPARE_HOURS},
                             decision_rule="a wave starts only if now plus the mean finished "
                                           "wave length fits the limit with 15 minutes spare, "
                                           "and every higher tier is done",
                             decision="START" if rule["fits"] else "STOP_CLOCK_RULE")
                if not rule["fits"]:
                    self.stop_reason = (f"clock rule: wave {wave_no} of tier {tier} would end "
                                        f"at {rule['projected_end_hours']:.3f} h, past the "
                                        f"limit {self.T:.3f} h less 15 minutes")
                    break
                res = self.run_wave(specs, wave_no, do_probe=(wave_no == 1))
                self.waves.append({k: v for k, v in res.items() if k != "specs"})
                if res["stop"]:
                    self.stop_reason = res["stop"]
                else:
                    self.durations.append(res["seconds"])
                for r in res["specs"]:
                    if r.status in ("failed", "degenerate") and r.spec.attempt == 1:
                        queue.append(r.spec.retry())
                self.write_state()
            done = all((s.molecule, s.rerun, s.kind) in self.ok_slugs for s in plan[tier])
            self.tier_status[tier] = "finished" if done else (
                "ended with failures" if not queue and self.stop_reason is None else "cut")
            self.write_state()
            if tier == 1 and not done:
                if self.stop_reason is None:
                    self.stop_reason = "tier 1 did not finish: a run failed twice"
                void_run(self.results, f"{LABEL_INCOMPLETE} ({self.stop_reason})")
            if self.stop_reason:
                break
        write_record(self.results, cell={"stage": "generate", "event": "end"}, inputs=[],
                     metric="how the simulation session ended",
                     values={"stop_reason": self.stop_reason, "tiers": self.tier_status,
                             "waves": self.waves, "finished_runs": len(self.ok_slugs)},
                     threshold={}, decision_rule="tier 1 must finish for any verdict",
                     decision="STOPPED_EARLY" if self.stop_reason else "ALL_TIERS_RAN")
        self.write_state()
        return 0


def stage_generate(args) -> int:
    results = Path(args.results)
    ensure_run_state(results)
    if load_records(results, "cell"):
        raise StageFailure(f"{results} already holds run records; use a fresh results folder")
    return Generator(args).run()

def stage_extract(args) -> int:
    results = Path(args.results)
    ensure_run_state(results)
    try:
        import numpy  # noqa: F401
        use_np = True
    except Exception:
        use_np = False
        print("[extract] numpy unavailable: using the plain (slow) displacement code")
    have = {(r["cell"]["molecule"], r["cell"]["rerun"], r["cell"]["kind"], r["cell"]["attempt"])
            for r in load_records(results, "cell")}
    metas = []
    for mp in sorted((results / "cells").glob("*/run_meta.json")):
        metas.append((mp.parent, json.loads(mp.read_text())))
    metas.sort(key=lambda x: 0 if x[1]["kind"] != "extension" else 1)
    n = 0
    for raw, meta in metas:
        key = (meta["molecule"], meta["rerun"], meta["kind"], meta["attempt"])
        if args.missing_only and key in have:
            continue
        out = record_cell(results, raw, meta, use_numpy=use_np)
        n += 1
        print(f"[extract] {raw.name}: {out['status']}")
    print(f"[extract] {n} run record(s) written")
    return 0

def collect_cells(results) -> dict:
    """Best record per (liquid, rerun, kind): the latest finished attempt."""
    best = {}
    for rec in load_records(results, "cell"):
        c = rec["cell"]
        key = (c["molecule"], c["rerun"], c["kind"])
        ok = rec["values"].get("status") == "ok"
        rank = (1 if ok else 0, c.get("attempt", 1))
        if key not in best or rank > best[key][0]:
            best[key] = (rank, rec)
    return {k: v[1] for k, v in best.items()}


def _ok(cells, key) -> bool:
    return key in cells and cells[key]["values"].get("status") == "ok"


def _msd_by_lag(rec) -> dict:
    return {int(round(r["lag_ps"] / FRAME_PS)): r["msd_A2"] for r in rec.get("rows") or []}


def _rule_outcome(void_label, decision, labels):
    """On a void run, state the rule's outcome but give no verdict."""
    if void_label is None:
        return decision, labels
    return "NO_VERDICT", [void_label]


def run_endpoints(results, manifest: dict, ref: dict, ref_inputs=None) -> dict:
    results = Path(results)
    ensure_run_state(results)
    cells = collect_cells(results)
    inputs = list(ref_inputs or [])
    calls = {}
    halts = []
    mm = {k: ref[k]["molar_mass"] for k in KEYS}
    eta = {k: ref[k]["eta"] for k in KEYS}
    eta_list = [eta[k] for k in KEYS]

    # Gates first: the pre-launch hand-off, tier 1, then the density gate.
    pre_ok = manifest.get("prelaunch_passed") is True
    if not pre_ok and read_run_state(results)["run_valid"]:
        void_run(results, LABEL_PRELAUNCH_VOID)
    tier1 = [(k, r, "main") for r in (1, 2) for k in KEYS]
    missing = [f"{k} rerun {r}" for k, r, _ in tier1 if not _ok(cells, (k, r, "main"))]
    complete = not missing
    if not complete:
        void_run(results, f"{LABEL_INCOMPLETE} (tier 1 cells missing: {missing})")
    finished = {k: [r for r in RERUNS if _ok(cells, (k, r, "main"))] for k in KEYS}
    dens_r = {k: {r: cells[(k, r, "main")]["values"]["density_last250ps"] for r in finished[k]}
              for k in KEYS}
    dmain = {k: {r: cells[(k, r, "main")]["values"]["D_A2_per_ps"]["main"] for r in finished[k]}
             for k in KEYS}
    dens = {k: mean(dens_r[k].values()) if dens_r[k] else None for k in KEYS}
    all_have = all(finished[k] for k in KEYS)

    # Endpoint 1, restated from the pre-launch record.
    e1 = manifest.get("endpoint1", {})
    write_record(results, cell={"stage": "endpoints", "endpoint": 1}, inputs=inputs,
                 metric="data-only pre-check (from the pre-launch record)", values=e1,
                 threshold={"rho": 1.0}, decision_rule="rho 1.0 and the stated order; a "
                 "failure stops the run before any spend",
                 decision="PASS" if e1.get("passed") else "FAIL",
                 labels=[LABEL_INTEGRITY] if e1.get("passed") else [])
    calls[1] = "PASS" if e1.get("passed") else "FAIL"

    # Endpoint 11, restated from the pre-launch record.
    ps = manifest.get("planted_summary", {})
    write_record(results, cell={"stage": "endpoints", "endpoint": 11}, inputs=inputs,
                 metric="planted known truth (from the pre-launch record)", values=ps,
                 threshold={"band_fraction": BAND_FRACTION},
                 decision_rule="bias within 2 standard errors; a band holding 95% of ordinary "
                               "slopes with 95% of power-law slopes outside; every label "
                               "reachable", decision="PASS" if ps.get("passed") else "FAIL")
    calls[11] = "PASS" if ps.get("passed") else "FAIL"

    # Endpoint 2: the density gate.
    gate = density_gate(dens)
    gate_fail = complete and not gate["passed"]
    if gate_fail:
        void_run(results, LABEL_UNTRUSTED)
    st = read_run_state(results)
    void_label = None
    if not st["run_valid"]:
        void_label = (LABEL_PRELAUNCH_VOID if not pre_ok else
                      LABEL_INCOMPLETE if not complete else
                      LABEL_UNTRUSTED if gate_fail else
                      "run void: " + "; ".join(st["voided_by"]))
    dec2 = "PASS" if gate["passed"] else "FAIL"
    if not complete:
        dec2 = "NO_VERDICT"
    write_record(results, cell={"stage": "endpoints", "endpoint": 2}, inputs=inputs,
                 metric="density gate: mean of the last 250 ps of the constant-pressure stage, "
                        "averaged over finished reruns", values=dict(gate, per_rerun=dens_r),
                 threshold={k: MOL[k]["band"] for k in KEYS},
                 decision_rule="all eight inside their bands; any outside fails the gate, the "
                               "ranking is labelled untrusted and the run is void",
                 decision=dec2, labels=[LABEL_INCOMPLETE] if not complete else
                 ([LABEL_UNTRUSTED] if gate_fail else []),
                 rows=[dict(molecule=k, **gate["per_molecule"][k]) for k in KEYS])
    calls[2] = dec2

    # Endpoint 3: the main rank correlation.
    proxy = {}
    main_rho = None
    if all_have:
        for k in KEYS:
            proxy[k] = proxy_mpas(mean(dmain[k].values()), dens[k], mm[k])
        main_rho = spearman([proxy[k] for k in KEYS], eta_list)
    hits = exact_rho_chance(main_rho) if main_rho is not None else (None, 40320)

    # Endpoint 10's windows feed endpoint 3's label, so compute them now.
    alt = {}
    if all_have:
        for w in ("early", "late"):
            p = {k: proxy_mpas(mean(cells[(k, r, "main")]["values"]["D_A2_per_ps"][w]
                                    for r in finished[k]), dens[k], mm[k]) for k in KEYS}
            alt[w] = spearman([p[k] for k in KEYS], eta_list)
    # Endpoint 9's label also feeds endpoint 3.
    half = manifest.get("slope_band_half_width")
    slopes9 = {}
    if all_have and half is not None:
        for k in KEYS:
            curves = [_msd_by_lag(cells[(k, r, "main")]) for r in finished[k]]
            lags = sorted(set.intersection(*[set(c) for c in curves]))
            avg = {m: mean(c[m] for c in curves) for m in lags}
            slopes9[k] = fit_loglog(avg, *LAG_WINDOWS_PS["main"])
    flagged = [k for k in KEYS if k in slopes9 and outside_band(slopes9[k], half)]
    nd_labels = nondiffusive_label(len(flagged)) if slopes9 else []
    w_labels = window_label(main_rho, list(alt.values())) if main_rho is not None and alt else []

    if main_rho is not None:
        d3, l3 = main_decision(main_rho)
        l3 = l3 + (w_labels if d3 == "PASS" else []) + nd_labels
    else:
        d3, l3 = "NO_VERDICT", []
    d3, l3 = _rule_outcome(void_label, d3, l3)
    rule3 = main_decision(main_rho)[0] if main_rho is not None else None
    write_record(results, cell={"stage": "endpoints", "endpoint": 3}, inputs=inputs,
                 metric="main: rho between the proxy and the reference viscosities",
                 values={"rho": main_rho, "sum_squared_rank_differences":
                         rank_sumsq([proxy[k] for k in KEYS], eta_list) if proxy else None,
                         "chance_at_least_this_rho": None if hits[0] is None else
                         {"orders": hits[0], "of": hits[1], "fraction": hits[0] / hits[1]},
                         "proxy_mpas": proxy, "rule_outcome": rule3,
                         "chance_rho_0.8": CHANCE["rho_0.8"], "chance_rho_0.6": CHANCE["rho_0.6"],
                         "flagged_non_diffusive": flagged},
                 threshold={"rho": RHO_BAR, "abandon": ABANDON_RHO},
                 decision_rule="rho >= 0.8 passes for this form; rho < 0.8 with the density "
                               "gate passed refutes this form only; rho < 0.6 also meets the "
                               "abandon line", decision=d3, labels=l3,
                 rows=[{"molecule": k, "D_mean_A2_per_ps": mean(dmain[k].values())
                        if dmain[k] else None, "density": dens[k],
                        "radius_m": radius_m(mm[k], dens[k]) if dens[k] else None,
                        "proxy_mpas": proxy.get(k), "reference_mpas": eta[k],
                        "reruns": finished[k]} for k in KEYS])
    calls[3] = d3

    # Endpoint 4: stability across reruns.
    complete_reruns = [r for r in RERUNS if all(r in finished[k] for k in KEYS)]
    per_rerun = {}
    for r in complete_reruns:
        per_rerun[r] = {k: proxy_mpas(dmain[k][r], dens_r[k][r], mm[k]) for k in KEYS}
    pairs = {f"{a}-{b}": spearman([per_rerun[a][k] for k in KEYS], [per_rerun[b][k] for k in KEYS])
             for a, b in itertools.combinations(complete_reruns, 2)}
    own = {str(r): spearman([per_rerun[r][k] for k in KEYS], eta_list) for r in complete_reruns}
    d4 = stability_decision(pairs)
    rule4 = d4
    d4, l4 = _rule_outcome(void_label, d4, [LABEL_RERUNS])
    write_record(results, cell={"stage": "endpoints", "endpoint": 4}, inputs=inputs,

                 values={"pair_rho": pairs, "own_rho_against_reference": own,
                         "own_rho_min": min(own.values()) if own else None,
                         "own_rho_max": max(own.values()) if own else None,
                         "reruns_complete": complete_reruns, "rule_outcome": rule4},
                 threshold={"rho": RHO_BAR}, decision_rule="every rerun pair at 0.8 or more; "
                 "with two finished reruns the single pair is judged", decision=d4, labels=l4)
    calls[4] = d4

    # Endpoint 5: agreement with the longer run.
    ext_ok = all(_ok(cells, (k, 1, "extension")) for k in KEYS)
    joins = {k: (cells[(k, 1, "extension")]["values"].get("join") or {}) if (k, 1, "extension")
             in cells else {} for k in KEYS}
    join_ok = ext_ok and all(joins[k].get("passed") for k in KEYS)
    rho5, side_b_reruns = None, {}
    if ext_ok and join_ok and all(1 in finished[k] for k in KEYS):
        side_a = {k: proxy_mpas(cells[(k, 1, "extension")]["values"]["D_A2_per_ps"]["long"],
                                dens_r[k][1], mm[k]) for k in KEYS}
        side_b = {}
        for k in KEYS:
            rs = [r for r in (2, 3) if r in finished[k]]
            side_b_reruns[k] = rs
            side_b[k] = proxy_mpas(mean(dmain[k][r] for r in rs),
                                   mean(dens_r[k][r] for r in rs), mm[k]) if rs else None
        if all(v is not None for v in side_b.values()):
            rho5 = spearman([side_a[k] for k in KEYS], [side_b[k] for k in KEYS])
    if rho5 is None:
        d5 = "NOT_JUDGED"
        note5 = ("tier 2 did not finish" if not ext_ok else
                 "the join check failed on an extended run" if not join_ok else
                 "a side had no finished rerun")
    else:
        d5 = "PASS" if rho5 >= RHO_BAR - 1e-12 else "REFUTED"
        note5 = ""
    rule5 = d5
    d5, l5 = _rule_outcome(void_label, d5, [LABEL_LONGER])
    write_record(results, cell={"stage": "endpoints", "endpoint": 5}, inputs=inputs,
                 metric="agreement of rerun 1 continued to 2 ns with the mean of reruns 2 and 3",

                         "join_checks": joins, "rule_outcome": rule5},
                 threshold={"rho": RHO_BAR}, decision_rule="rho >= 0.8; if tier 2 did not "
                 "finish, or a join check failed, the endpoint is not judged",
                 decision=d5, labels=l5)

                    or 0.0 for r in finished[k]) for k in KEYS}

    l6 = [LABEL_COST]
    if calls[4] == "REFUTED" or rule4 == "REFUTED":

    d6, l6 = _rule_outcome(void_label, d6, l6)

    else:

    rule7 = d7
    d7, l7 = _rule_outcome(void_label, d7, l7)

                 threshold={"concordant_min": FAMILY_MIN}, decision_rule="at least 10 of 12 "
                 "within-family pairs in reference order; fewer refutes claim 4",

def find_manifest(args) -> dict:
    for cand in (Path(args.systems) / "box_manifest.json",
                 prelaunch_dir(args.results) / "systems" / "box_manifest.json"):
        if cand.exists():
            return json.loads(cand.read_text())
    raise StageFailure("no box manifest found; pass --systems")


def stage_endpoints(args) -> int:
    ref, ref_inputs = read_reference(Path(args.root))
    res = run_endpoints(Path(args.results), find_manifest(args), ref, ref_inputs)
    if res["halts"]:
        print(f"[endpoints] {WRONG_VARIANCE} halted endpoint(s) {res['halts']}; every record "
              "was written; exit code 3")
        return 3
    return 0

def _planted_cell(results, k, r, kind, *, d, dens, slope_exp=1.0, d_early=None, d_late=None,
                  status="ok", time_axis_ok=True, join_passed=True, gpu=0.25):
    """A per-run record shaped exactly like the extract stage's output."""
    if kind == "extension":
        lags = lag_range(*LONG_LAGS_PS)
        dvals = {"long": d}
        win = "0.2-2.0 ns"
    else:
        lags = lag_range(50, 400)
        dvals = {"main": d, "early": d if d_early is None else d_early,
                 "late": d if d_late is None else d_late}
        win = "0.2-1.0 ns"
    rows = [{"window": win, "lag_ps": float(m),
             "msd_A2": 6.0 * d * (m ** slope_exp) / (100.0 ** (slope_exp - 1.0))} for m in lags]
    vals = {"molecule": k, "rerun": r, "kind": kind, "attempt": 1, "status": status,
            "flags": [] if status == "ok" else ["RUN_FAILED"], "n_molecules": MOL[k]["n_mol"],
            "timestep_fs": 1.0 if kind == "timestep1fs" else 2.0,
            "density_last250ps": dens, "density_plateau_020_045ns": dens,
            "D_A2_per_ps": dvals, "loglog_slope": {list(dvals)[0]: slope_exp},
            "time_axis": {"ok": time_axis_ok, "frame_spacing_ps": 1.0 if time_axis_ok else 0.5},
            "run": {"gpu_hours_share": gpu}}
    if kind == "extension":
        vals["join"] = {"passed": join_passed}
    write_record(results, cell={"stage": "cell", "molecule": k, "rerun": r, "kind": kind,
                                "attempt": 1}, inputs=[], metric="planted run", values=vals,
                 threshold={}, decision_rule=CELL_RULE, decision="CELL_" + status.upper(),
                 rows=rows)


def _plant_scenario(results, *, reverse=False, dens_override=None, drop=None, factors=None,
                    nondiff=(), early_scramble=False, ext=True, control=True,
                    control_factor=1.0, identical=False):
    mm = {k: molar_mass(MOL[k]["smiles"]) for k in KEYS}
    etas = {m["key"]: m["ref_eta"] for m in MOLECULES}
    if reverse:
        order = sorted(KEYS, key=lambda k: etas[k])
        rev_vals = sorted(etas.values(), reverse=True)
        etas = {k: v for k, v in zip(order, rev_vals)}
    fac = {k: (1.0, 1.0, 1.0) for k in KEYS}
    fac["squalane"] = (1.0, 1.0, 1.05)
    fac[CONTROL_KEY] = (1.0, 1.02, 0.98)
    if factors:
        fac.update(factors)
    if identical:
        fac = {k: (1.0, 1.0, 1.0) for k in KEYS}
    for k in KEYS:
        rho = MOL[k]["paper_rho"] if not dens_override or k not in dens_override \
            else dens_override[k]
        base = planted_d_a2ps(etas[k], rho, mm[k])
        for r in RERUNS:
            if drop and (k, r) in drop:
                continue
            d = base / fac[k][r - 1]
            early = d
            if early_scramble:
                early = planted_d_a2ps(1.0 + KEYS.index(k), rho, mm[k])
            _planted_cell(results, k, r, "main", d=d, dens=rho,
                          slope_exp=0.7 if k in nondiff else 1.0, d_early=early)
        if ext:
            _planted_cell(results, k, 1, "extension", d=base, dens=rho)
    if control:
        k = CONTROL_KEY
        base = planted_d_a2ps(etas[k], MOL[k]["paper_rho"], mm[k])
        _planted_cell(results, k, 1, "timestep1fs", d=base * control_factor,
                      dens=MOL[k]["paper_rho"])


def _planted_manifest(half=0.05) -> dict:
    return {"schema": "cp1_box_manifest_v1", "prelaunch_passed": True,
            "endpoint1": {"passed": True}, "planted_summary": {"passed": True},
            "slope_band_half_width": half}

def selftest() -> int:
    fails = []
    checks = [0]

    def check(name, cond, extra=""):
        checks[0] += 1
        if not cond:
            fails.append(f"{name} {extra}".strip())
            print(f"FAIL {name} {extra}")

    def approx(a, b, tol=1e-9):
        return a is not None and b is not None and abs(a - b) <= tol * max(1.0, abs(b))

    # --- the eight liquids: formulas, counts, bands, order ---
    formulas = {"squalane": {"C": 30, "H": 62}, "nonylcyclohexane": {"C": 15, "H": 30},
                "hexyldiphenylheptane": {"C": 25, "H": 36},
                "propylheptylnaphthalene": {"C": 20, "H": 28},
                "decylstearate": {"C": 28, "H": 56, "O": 2}, "sebacate": {"C": 26, "H": 50, "O": 4},
                "trioxanonadecane": {"C": 16, "H": 34, "O": 3},
                "glycolether": {"C": 12, "H": 26, "O": 5}}
    for k in KEYS:
        f = smiles_formula(MOL[k]["smiles"])
        check(f"formula {k}", f == formulas[k], str(f))
        apm = atoms_per_molecule(MOL[k]["smiles"])
        check(f"molecules per box {k}", round(TARGET_ATOMS / apm) == MOL[k]["n_mol"])
        lo, hi = MOL[k]["band"]
        check(f"band {k} is paper value +-2%",
              round(MOL[k]["paper_rho"] * 0.98, 3) == lo and round(MOL[k]["paper_rho"] * 1.02, 3) == hi)

    check("claim 5 passes; one over D adds a label only", av["decision"] == "PASS"
          and av["labels"] == [LABEL_SIZE])
    av = added_value_decision(0.9, DESIGN_FREE_RHO, 0.02, {"inverse_D": 0.1, "simulated_density": 0.9})
    check("simulated density adds a label only", av["decision"] == "PASS" and av["labels"] == [LABEL_DIFFUSION])
    mm = {k: molar_mass(MOL[k]["smiles"]) for k in KEYS}
    pref = _planted_ref(mm)
    dens0 = {k: MOL[k]["paper_rho"] for k in KEYS}
    base = {k: planted_d_a2ps(MOL[k]["ref_eta"], dens0[k], mm[k]) for k in KEYS}
    three = {k: [base[k], base[k], base[k] / (1.05 if k == "squalane" else 1.0)] for k in KEYS}
    m3 = added_value_margin(three, dens0, pref)
    check("margin over exactly 6,561 picks is positive", m3["n_picks"] == 6561 and m3["margin"] > 0)
    two = {k: [base[k], base[k] / (1.05 if k == "squalane" else 1.0)] for k in KEYS}
    m2 = added_value_margin(two, dens0, pref)
    check("margin over exactly 256 picks with two reruns", m2["n_picks"] == 256 and m2["margin"] > 0)
    try:
        added_value_margin({k: [base[k]] * 3 for k in KEYS}, dens0, pref)
        check("identical reruns halt the margin", False)
    except WrongVarianceSource:
        check("identical reruns halt the margin", True)
    ts = timestep_decision(1.0, [0.98, 1.0, 1.02], True, True)
    check("timestep pass", ts["decision"] == "PASS")
    ts = timestep_decision(1.1, [0.98, 1.0, 1.02], True, True)
    check("timestep conditional", ts["decision"] == "CONDITIONAL_ON_TIMESTEP" and LABEL_TIMESTEP in ts["labels"])
    check("timestep not run", timestep_decision(None, [1, 2], False, True)["decision"] == "NOT_JUDGED")
    check("timestep bad time axis", timestep_decision(1.0, [1, 2], True, False)["decision"] == "NOT_JUDGED")
    try:
        timestep_decision(1.0, [1.0, 1.0, 1.0], True, True)
        check("identical 2 fs reruns halt", False)
    except WrongVarianceSource:
        check("identical 2 fs reruns halt", True)
    dg = density_gate(dens0)
    check("density gate passes at paper values", dg["passed"] and
          all(dg["implications_report_only"].values()))
    off = dict(dens0)
    off[GLYCOL_KEY] *= DENSITY_OFF_FACTOR
    check("one density 5% off fails the gate", not density_gate(off)["passed"])
    check("band: 95% of 200", approx(slope_band([1.0 + 0.001 * i for i in range(200)]), 0.189))
    check("outside band", outside_band(0.7, 0.05) and not outside_band(1.03, 0.05)
          and outside_band(None, 0.05))
    check("non-diffusive label at 3", nondiffusive_label(3) == [LABEL_NONDIFF.format(n=3)]
          and nondiffusive_label(2) == [])
    check("window label", window_label(0.85, [0.7, 0.9]) == [LABEL_WINDOW]
          and window_label(0.75, [0.7]) == [] and window_label(0.85, [0.85, 0.9]) == [])
    bt = bias_test([1.01, 0.99, 1.02, 0.98], [1, 1, 1, 1])
    check("bias within 2 standard errors", bt["passed"])
    check("bias beyond 2 standard errors", not bias_test([1.10, 1.11, 1.09, 1.10], [1] * 4)["passed"])
    try:
        bias_test([1.0, 1.0], [1.0, 1.0])
        check("zero-spread planted bias halts", False)
    except WrongVarianceSource:
        check("zero-spread planted bias halts", True)

    # --- full endpoint runs on planted run records ---
    with tempfile.TemporaryDirectory(prefix="cp1_selftest_") as td:
        td = Path(td)

        def fresh(name):
            d = td / name
            d.mkdir()
            ensure_run_state(d)
            return d

        def recs(d):
            return {p.name: json.loads(p.read_text()) for p in Path(d).glob("*.json")
                    if p.name not in STATE_NAMES}

        # A: a clean pass
        a = fresh("pass")
        _plant_scenario(a)
        before = recs(a)
        check("planted run records start valid", all(r["run_valid"] for r in before.values()))
        ra = run_endpoints(a, _planted_manifest(), eref)
        c = ra["calls"]
        check("pass: run valid", ra["run_valid"] is True and not ra["halts"])
        check("pass: gate", c[2] == "PASS")
        check("pass: main", c[3] == "PASS", str(c))
        check("pass: stability", c[4] == "PASS")
        check("pass: longer run", c[5] == "PASS")
        check("pass: cost", c[6] == "MET_BY_PLAN_ARITHMETIC")
        check("pass: families", c[7] == "PASS")
        check("pass: added value", c[8] == "PASS", str(c[8]))
        check("pass: no slope label", c[9] == "NO_LABEL")
        check("pass: same in all windows", c[10] == "SAME_IN_ALL_WINDOWS")
        check("pass: timestep", c[12] == "PASS")
        ra_recs = recs(a)
        e3 = ra_recs["endpoint-3_stage-endpoints.json"]
        check("pass: main rho is 1", approx(e3["values"]["rho"], 1.0))
        check("pass: chance of rho 1 is 1/40320", e3["values"]["chance_at_least_this_rho"]["orders"] == 1)
        check("pass: main label", LABEL_PASS_FORM in e3["labels"])
        e8 = ra_recs["endpoint-8_stage-endpoints.json"]
        check("pass: 6,561 picks", e8["values"]["n_picks"] == 6561)
        e6 = ra_recs["endpoint-6_stage-endpoints.json"]
        check("pass: cost label", LABEL_COST in e6["labels"]
              and e6["values"]["ns_per_molecule"]["squalane"] == 3.375)
        check("pass: every record carries run_valid", all("run_valid" in r for r in ra_recs.values()))
        check("pass: summary valid", ra_recs["stage-summary_tag-cp1.json"]["decision"] == "RUN_VALID")

        # B: reversed order refutes this form only
        b = fresh("reversed")
        _plant_scenario(b, reverse=True, factors={CONTROL_KEY: (1.0, 1.02, 0.95)})
        rb = run_endpoints(b, _planted_manifest(), eref)
        e3b = recs(b)["endpoint-3_stage-endpoints.json"]
        check("reversed: main refuted below the abandon line",
              rb["calls"][3] == "REFUTED_BELOW_ABANDON_LINE" and approx(e3b["values"]["rho"], -1.0))
        check("reversed: form-only label", LABEL_FORM_ONLY in e3b["labels"])
        check("reversed: families refuted", rb["calls"][7] == "REFUTED")
        check("reversed: added value refuted", rb["calls"][8] == "REFUTED")
        check("reversed: run stays valid", rb["run_valid"] is True)

        # C: a planted gate failure must void every record, before and after
        cdir = fresh("gatefail")
        dens_bad = {GLYCOL_KEY: MOL[GLYCOL_KEY]["paper_rho"] * DENSITY_OFF_FACTOR}
        _plant_scenario(cdir, dens_override=dens_bad)
        pre_cells = set(recs(cdir))
        check("gate fail: run records valid before endpoints",
              all(r["run_valid"] for r in recs(cdir).values()))
        rc_ = run_endpoints(cdir, _planted_manifest(), eref)
        after = recs(cdir)
        check("gate fail: gate fails", rc_["calls"][2] == "FAIL")
        check("gate fail: run void", rc_["run_valid"] is False)
        check("gate fail: void reaches every record",
              all(r["run_valid"] is False for r in after.values()),
              str([n for n, r in after.items() if r["run_valid"] is not False]))
        check("gate fail: run records voided after the fact",
              all(after[n].get("run_valid_voided_retroactively") is True for n in pre_cells))
        check("gate fail: void reason recorded", all(r["run_valid_voided_by"] for r in after.values()))
        check("gate fail: main gives no verdict", rc_["calls"][3] == "NO_VERDICT"
              and LABEL_UNTRUSTED in after["endpoint-3_stage-endpoints.json"]["labels"])
        check("gate fail: rule outcome still stated",
              after["endpoint-3_stage-endpoints.json"]["values"]["rule_outcome"] == "PASS")
        check("gate fail: summary void", after["stage-summary_tag-cp1.json"]["decision"] == "RUN_VOID")
        check("gate fail: validity file false", read_run_state(cdir)["run_valid"] is False)
        ensure_run_state(cdir)
        check("gate fail: a void is never undone", read_run_state(cdir)["run_valid"] is False)
        write_record(cdir, cell={"stage": "later", "n": 1}, inputs=[], metric="m", values={},
                     threshold={}, decision_rule="r", decision="X")
        check("gate fail: a later record is born void",
              json.loads((cdir / "n-1_stage-later.json").read_text())["run_valid"] is False)

        # D: tier 1 missing a run: incomplete, descriptive only
        dd = fresh("incomplete")
        _plant_scenario(dd, drop={("sebacate", 2)})
        rd_ = run_endpoints(dd, _planted_manifest(), eref)
        drec = recs(dd)
        check("incomplete: run void", rd_["run_valid"] is False)
        check("incomplete: label on every endpoint",
              all(LABEL_INCOMPLETE in drec[f"endpoint-{n}_stage-endpoints.json"]["labels"]
                  for n in (3, 4, 5, 6, 7)), "")
        check("incomplete: no pass or refutation",
              all(rd_["calls"][n] in ("NO_VERDICT",) for n in (3, 4, 5, 6, 7, 8, 9, 10, 12)),
              str(rd_["calls"]))

        # E: zero dispersion over reruns halts endpoints 8 and 12
        e = fresh("identical")
        _plant_scenario(e, identical=True)
        re_ = run_endpoints(e, _planted_manifest(), eref)
        check("identical reruns: endpoint 8 halts", re_["calls"][8] == WRONG_VARIANCE)
        check("identical reruns: endpoint 12 halts", re_["calls"][12] == WRONG_VARIANCE)
        check("identical reruns: halts reported", re_["halts"] == [8, 12])
        check("identical reruns: every record still written",
              "stage-summary_tag-cp1.json" in recs(e))

        # F: labels that never refute
        f = fresh("labels")
        _plant_scenario(f, nondiff=("squalane", "hexyldiphenylheptane", "sebacate"),
                        early_scramble=True)
        rf_ = run_endpoints(f, _planted_manifest(), eref)
        frec = recs(f)
        check("labels: three non-diffusive add the label", rf_["calls"][9] == "LABEL_ADDED"
              and LABEL_NONDIFF.format(n=3) in frec["endpoint-9_stage-endpoints.json"]["labels"])
        check("labels: window-dependent", rf_["calls"][10] == "WINDOW_DEPENDENT")
        check("labels: main still passes with both labels", rf_["calls"][3] == "PASS"
              and LABEL_WINDOW in frec["endpoint-3_stage-endpoints.json"]["labels"]
              and LABEL_NONDIFF.format(n=3) in frec["endpoint-3_stage-endpoints.json"]["labels"])
        check("labels: run stays valid", rf_["run_valid"] is True)

        # G: endpoint 5 and 12 not judged; stability refuted marks cost not shown
        g = fresh("partial")
        _plant_scenario(g, ext=False, control=False,
                        factors={"glycolether": (1.0, 1.0, 0.3), "trioxanonadecane": (1.0, 1.0, 3.0)})
        rg = run_endpoints(g, _planted_manifest(), eref)
        grec = recs(g)
        check("partial: longer run not judged", rg["calls"][5] == "NOT_JUDGED")
        check("partial: timestep not judged", rg["calls"][12] == "NOT_JUDGED")
        check("partial: stability refuted", rg["calls"][4] == "REFUTED", str(grec[
            "endpoint-4_stage-endpoints.json"]["values"]["pair_rho"]))
        check("partial: cost not shown", f"claim 3: {LABEL_NOT_SHOWN}" in
              grec["endpoint-6_stage-endpoints.json"]["labels"])
        check("partial: F2 readout not run",
              grec["readout-long-lag-slope_stage-endpoints.json"]["decision"] == "NOT_RUN")

        # H: a failed pre-launch hand-off voids everything
        h = fresh("prelaunch")
        _plant_scenario(h)
        man_bad = _planted_manifest()
        man_bad["prelaunch_passed"] = False
        rh = run_endpoints(h, man_bad, eref)
        check("failed pre-launch voids the run", rh["run_valid"] is False and
              all(r["run_valid"] is False for r in recs(h).values()))

        # I: a join failure on one extended run leaves endpoint 5 not judged
        i_ = fresh("joinfail")
        _plant_scenario(i_)
        _planted_cell(i_, "squalane", 1, "extension",
                      d=planted_d_a2ps(15.06, 0.804, mm["squalane"]), dens=0.804,
                      join_passed=False)
        ri = run_endpoints(i_, _planted_manifest(), eref)
        check("join failure: endpoint 5 not judged", ri["calls"][5] == "NOT_JUDGED")

        # J: the pre-launch folder is never stamped by a box void
        j = fresh("nested")
        (j / "prelaunch").mkdir()
        write_record(j / "prelaunch", cell={"stage": "prelaunch", "step": "x"}, inputs=[],
                     metric="m", values={}, threshold={}, decision_rule="r", decision="PASS")
        void_run(j, "test void")
        check("box void never touches the pre-launch folder",
              json.loads((j / "prelaunch" / "stage-prelaunch_step-x.json").read_text())
              ["run_valid"] is True)

        # Wording: no output describes reruns as something they are not
        texts = [p.read_text() for p in td.rglob("*.json")]
        check("no output calls reruns replication",
              not any("replicat" in t.lower() for t in texts) and "replicat" not in
              (LABEL_RERUNS + __doc__).lower())

        # Provenance writer round trip
        prov = provenance()
        check("records are named by their identity",
              (a / (prov.cell_slug({"stage": "endpoints", "endpoint": 3}) + ".json")).exists())

    print(f"selftest: {checks[0]} checks, " + ("PASS" if not fails else f"{len(fails)} FAILURES"))
    return 1 if fails else 0


# ---------------------------------------------------------------------------
# Command line
# ---------------------------------------------------------------------------
def main(argv=None) -> int:
    if argv is None:
        argv = sys.argv[1:]
    if "--selftest" in argv:
        return selftest()
    ap = argparse.ArgumentParser(description="Runner for the coolant proxy experiment (cp1).")
    ap.add_argument("stage", choices=["prelaunch", "engine", "verify", "generate", "extract",
                                      "endpoints"])
    ap.add_argument("--root", default=str(HERE), help="folder holding data/ (default: here)")
    ap.add_argument("--results", default=str(HERE / "out" / "results_cp1"))
    ap.add_argument("--systems", default=None,
                    help="built boxes; default systems_cp1 on the box, prelaunch/systems locally")
    ap.add_argument("--work", default=str(HERE / "work_cp1"))
    ap.add_argument("--toolchain", default=str(HERE / ".toolchain" / "env"))
    ap.add_argument("--step", choices=PRELAUNCH_STEPS, default=None)
    ap.add_argument("--lmp", default=None)
    ap.add_argument("--mpirun", default=None)
    ap.add_argument("--env-prefix", default=None)
    ap.add_argument("--missing-only", action="store_true")
    args = ap.parse_args(argv)
    if args.systems is None and args.stage != "prelaunch":
        args.systems = str(HERE / "systems_cp1")
    if args.stage in ("engine", "generate") and not args.lmp:
        ap.error("--lmp is required for this stage")
    try:
        if args.stage == "prelaunch":
            return stage_prelaunch(args)
        if args.stage == "engine":
            return stage_engine(args)
        if args.stage == "verify":
            return stage_verify(args)
        if args.stage == "generate":
            return stage_generate(args)
        if args.stage == "extract":
            return stage_extract(args)
        if args.stage == "endpoints":
            return stage_endpoints(args)
    except StageFailure as e:
        print(f"[FATAL] {e}", file=sys.stderr)
        return 2
    return 0


if __name__ == "__main__":
    sys.exit(main())
